# 角色与回复风格

### 用途

查看和选择角色，添加新的角色，调整回复长短、称呼和语气。

### 使用示例

```text
@机器人 有哪些角色可以选？
@机器人 切换成通用助手
@机器人 联网添加《原神》的安柏并选用
@机器人 以后叫我阿阳，回复简短一点，少用表情
```

### 返回内容与注意事项

机器人会说明当前角色、变更结果或添加失败的原因。联网添加会查找资料；未成功添加时不会假装已经保存。你创建的角色和表达偏好归属于你，不会替其他群成员切换。

角色会影响语气，不改变查询权限、事实和任务发送对象。选择通用助手可关闭虚构角色风格。想看这一次的更多依据，可以直接要求展开，不必修改长期偏好。
