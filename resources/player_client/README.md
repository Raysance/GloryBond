# 玩家客户端界面模板

个人资料、对战数据、单英雄表现及英雄列表现统一使用 `gen_player_summary.py` 的浅色卡片，不依赖截图背景。个人资料分为基础数值、本赛季、巅峰赛、我的分路；对战数据分为时间/分路筛选、场次/胜率/综合得分、能力雷达、对局荣誉；单英雄增加头像、最高战力、赛年标签与历史称号；英雄列表采用头像表格，默认最多10行。玩家名称来自同一目标的官方 profile，不展示配置别名。只绘制数据和必要标签，未知值显示—，使用下述同一套原应用字体。

hero.jpg、game.jpg、heroes.jpg 是用户提供的三张游戏截图，分别对应个人荣誉、对战资料和英雄列表界面。现仅作为旧版静态模板和兼容渲染保留，当前查询不使用这些背景。旧版 gen_player_client.py 会清除示例统计、标签、卡片、分路段位和雷达填充，再写入白名单字段。

未取得的字段仅以“—”或空雷达框占位，具体缺项只在图外文字说明，不能将原截图中的数字留作真实结果。卡片图片、名称和统计栏使用同一组精确列坐标；英雄列表使用官方 mobileskin 立绘居中裁切，新英雄使用官方默认插画；小乔个人荣誉沿用原模板的同一默认形象。缓存不保存到此目录。

0.6.16 页面视图补充原生评分/雷达、使用中的赛年标签、历史徽章次数、历史称号地区与名次、战斗风格和分路段位。游戏显示值来自分路加权 display，不能以原始汇总行替代；英雄荣誉采用自己的原生分母和评分转换。图中不添加解释性文案。

动态文字使用原应用随包字体，常规字重为 Ex_GameFontYaHei.ttf（FZLanTingHeiS-R-GB），粗体为 Ex_GameFont.ttf（FZZhengHeiS-DB-GB）。字体路径分别由 PlayerClient.report_font_path / report_bold_font_path 配置，经 zfile.player_client_report_font() 加载，不依赖主机字体。固定文字保留截图字形。来源和布局提取范围见 [native-ui.md](native-ui.md)。

装备名称目录 equipment.json 来自[王者荣耀官网装备列表](https://pvp.qq.com/web201605/js/item.json)，更新于2026-10-24，图标使用官网同 ID 的 itemimg 资源。共鸣技能名称和来源英雄使用 hok_player_client 0.6.19 的明确配置映射，装备效果不强行关联英雄。网页详情和分享图片均按四个选择槽的原顺序展示；旧对局可通过既有离线回填命令补齐。
