# 当前对局观战截图

发送 `#观战昵称` 或 `#观战配置简称` 查询已登记玩家；`#观战我` 和 `#我的观战` 使用发送者绑定的游戏账号。

机器人先回复正在获取，成功后返回一张当前直播截图。等待画面分配最多60秒，随后读取视频的超时为10秒；首次返回可能是游戏加载画面。截图取得后立即关闭本次观战，不持续推送图片。

目标未开局、当前对局不允许观战、等待超时或读取失败时会给出提示。失败不会自动重新登录或重复申请。正在获取另一张截图时会提示稍后再试，避免同时发起多个观战。直播画面可能有服务端延迟，不保证与玩家手机同一时刻。

该命令沿用前缀命令的权限和玩家登记规则。未知昵称或未绑定的“我”不会触发查询，也不接受任意直播地址。返回的是画面图片，不包含账号凭据或带签名的播放链接。旧 `#我ob` 入口保留；`#我的预言` 继续用于当前对局双方实力分析。
