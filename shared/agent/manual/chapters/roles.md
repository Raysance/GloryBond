# 角色与回复风格

### 用途

查看和选择角色，添加新的角色，调整回复长短、称呼和语气。超级管理员还可以给指定QQ用户切换角色。

### 使用示例

```text
@机器人 有哪些角色可以选？
@机器人 切换成通用助手
@机器人 联网添加《原神》的安柏并选用
@机器人 以后叫我阿阳，回复简短一点，少用表情
@机器人 把 @某人 的角色换成通用助手
@机器人 给QQ 123456789添加《原神》的安柏并选用
```

### 返回内容与注意事项

机器人会说明当前角色、变更结果或添加失败的原因。联网添加会查找资料；未成功添加时不会假装已经保存。普通用户管理自己的角色和表达偏好。

配置的QQ超级管理员可以按明确QQ、原生@或权威名称映射指定目标，先查看目标的角色目录，再为其选择已有角色；目录里没有所需角色时，可为目标联网添加并选用。群聊内会确认目标仍是当前群成员，超级管理员私聊可以明确指定目标QQ。只有角色选择和角色库作用于该目标，称呼、回复长短、个人偏好和权限保持原样；管理员本人的角色和本次回复对象也保持原样。普通群管理员或群主身份不自动取得这项权限，本地网页也不会因默认用户恰好是管理员而自动获得代改权限。

切换后，目标用户同一QQ在群聊、私聊和绑定该身份的网页端共用新角色，之后的对话和后台agent任务读取最新选择。目标用户仍可自行换回其他角色。

角色会影响语气，不改变查询权限、事实和任务发送对象。选择通用助手可关闭虚构角色风格，默认坚定、有主见，直接给出判断与理由，发现错误会明确指出。用户当次要求和已保存的语气偏好可调整表达。想看这一次的更多依据，可以直接要求展开，不必修改长期偏好。
