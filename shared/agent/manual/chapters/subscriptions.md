# 视频订阅与自动推送

### B站 UP订阅

| 操作 | 使用示例 |
| --- | --- |
| 订阅 UP | #订阅B站 罗翔 |
| 查看当前订阅 | #我的订阅 |
| 查订阅 UP的最新视频 | #最新视频 |
| 取消某个订阅 | #取消订阅 罗翔 |
| 取消本人全部订阅 | #取消订阅 |

订阅成功后，机器人会按轮询结果推送新视频。可以订阅多个 UP；重名、无法搜索或找不到账号时，需要补充信息。取消订阅会给出结果。它是 QQ业务命令，AI 聊天没有独立的 UP订阅操作工具。

### X 账号订阅

| 操作 | 使用示例 |
| --- | --- |
| 订阅账号 | #订阅X @XDevelopers |
| 用主页链接订阅 | #订阅X https://x.com/XDevelopers |
| 查看本人订阅 | #我的X订阅 |
| 查看订阅账号最新内容 | #X最新内容 |
| 取消指定账号 | #取消X订阅 @XDevelopers |

用户名不区分大小写，支持 x.com 和 twitter.com 主页链接，不支持按显示昵称搜索。可以订阅多个账号；取消命令未指定账号时，只有本人恰好订阅一个账号才直接取消。X 与 B站订阅独立，`#我的订阅`、`#最新视频` 等原 B站命令不变。AI 聊天仅能说明用法，未增加隐式订阅工具。

默认每5分钟轮询原创公开帖子，排除转帖与账号自己的回复。新帖至少发布5分钟后才自动推送，为评论积累留出时间。订阅首次返回最新帖预览，自动推送不补旧帖。订阅记录按真实 QQ 用户保存，自动消息与 B站一样发送到配置的 QQ 群，同一账号多人订阅只推一次。

推送参照 B站消息的分块排版：首行显示作者与发帖时间，例如 `Tibo · 2026-10-14 07:32:43（1天前）`；换行显示中文译文预览（没有译文的中文帖子直接显示原文），再换行附图片卡片；全部图片之后换行附可点击的原帖链接。各部分之间不额外添加空行，文字预览压缩空白行，图片保留完整内容。文字优先采用翻译后的中文，预览默认最多280字符，超出后显示“……全文见图”，完整原文及译文放在图片中。文字中的时间取原帖发布时间，以北京时间显示到秒，不使用当前时间；时间后附“刚刚／几分钟前／几小时前／几天前”等描述，按消息生成时刻计算；预览保留必要换行，短帖译文直接完整显示。图片包含原帖正文、可读取的图片或视频预览、热门回复、英文原文及中文 AI 译文，卡片时间为原帖发表时间；视频本体可通过末尾原帖链接观看。图片中的原文与译文不按字符数截断，长内容拆为多张图片。热门回复从网页登录会话可见的公开会话回复中采样，默认最多100条，按点赞数选取5条，包含楼中楼；这不是 X 全量或官方热门排名。刚发布、无回复、私密、登录失效、限流或网页结构变化时，卡片会标注实际情况。翻译失败时文字区与图片均保留原文并明确标注，不编造译文。回复和点赞为生成时快照，不持续更新已推送图片。

管理员通过 `##x list` 查看订阅，`##x check` 立即检查并执行符合条件的新帖推送。读取走 X 网页内部 GraphQL，网页签名与基础协议使用 Twikit，项目负责只读调用、解析和分页；不使用开发者 API，不需要开发者 Bearer Token。先在浏览器正常登录自己的 X 账号，打开开发者工具的 Application/存储 → Cookies → https://x.com，复制 `auth_token` 与 `ct0` 的值，分别填入现有 `.env` 的 `HOK_X_AUTH_TOKEN` 和 `HOK_X_CT0`。Cookie 是登录凭据，仅在本地配置，不要粘贴到群聊或分享页。会话过期时需重新登录并更新这两项，程序不自动登录或解锁账号。

非密钥参数统一在 `config.yaml#XSubscriptions`，请求使用已有 `Proxy.clash_url`，禁用环境代理继承。未配会话时定时任务不访问 X，主动订阅会返回配置提示。程序从当前网页脚本获取查询操作 ID；网页接口变化时，可更新适配或配置 `web_query_ids`、`web_features`。网页服务不保证一直可读取，不会自动切换开发者付费 API。

网页返回不完整数据、分页超过预算或消息未能入队时不跳过对应帖子；其他账号仍独立检查。生成图片失败保留待推帖子；回复或翻译暂时失败时仍发送有明确缺失标记的卡片。

### AI 领域日报

默认每天北京时间09:00向配置的 QQ 群发送一条合并转发日报，打开聊天记录即可阅读，无需个人订阅。内容涵盖模型更新、产品发布、行业动态、论文研究、技巧与观点。

第一条消息为本期所有资讯的分点汇总，附日期，先看这一条就能了解当天要点。后面按相同编号逐条展开标题、摘要和原文链接，快讯也纳入统一编号。不再显示生成时间、统计区间、分类计数、信源名称、聚合站链接或重复的来源说明。长内容自动分节点并保留完整摘要；总览始终为一个节点，必要时缩短过长的总览标题，详情标题仍保留全文。重复资讯合并，没有新增内容时明确说明。

只推当日版本，同一群同一日期防重复。接口失败、尚未发布当期、返回结构异常或超过内容预算时，不把旧内容当成新日报，管理员会收到失败提示。QQ 转发发送失败或结果未知时不会自动重复发送，以免重复推送；需管理员检查日志处理。消息入队后重启仍保留队列与防重复状态。

开关、时间、时区、接口地址、超时、内容预算及署名统一在 `config.yaml#AIDaily`，目的地沿用 `QQBot.group_qid`。默认不增加用户查询命令，也不影响原有游戏新闻和每日战报。

### 每日战报与赛事通知

当前每日23:30向配置的群发送当日战报及代表局内容；无需每位用户重复安排。代表局按文字、图片、点评的顺序展示。

KPL赛事战报生成仍有管理员入口，但自动 KPL轮询推送目前未默认启用。旧手册中的“自动触发”不能作为现在必定收到赛事通知的保证。
