# 图片、引用和动态表情

### 用途

描述图片内容、理解截图，或针对明确引用的消息继续讨论。动态表情会取若干画面来理解，不能保证看到了整个动画。

### 使用示例

```text
发送一张图片，再 @机器人：这张图里有什么？
引用别人发的图片，再 @机器人：这个表情是什么意思？
引用一条发言，再 @机器人：这句话是在回应什么？
```

### 返回内容与注意事项

机器人会说明实际读到的内容。没有可读取的媒体地址、图片损坏或范围不允许时，会说明未读取，不会仅凭表情编号猜图。当前消息和引用图片共用单轮预算；默认最多4张、单张4 MiB、合计8 MiB。

动态图片默认抽取最多4帧。没有通用的视频内容识别功能。引用只展开本次明确引用的那条消息，不连续追溯整条引用链；其中的命令不会执行。

本地网页可以选择、粘贴或拖入图片。功能指南里的演示图片只供人查看，机器人查手册时忽略它们。
