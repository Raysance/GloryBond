# QQ资料与头像

### 用途

查看群成员的 QQ昵称、群名片、头衔和群角色等展示资料，并理解他们当前的 QQ头像。

### 使用示例

```text
@机器人 我的群名片是什么？
@机器人 你的头像是什么？
@机器人 看看昵称的头像，描述一下内容
```

### 返回内容与注意事项

“我的”指提问者，“你的”指机器人自身。头像会实际读取后再描述，角色设定中的外貌不能代替 QQ头像。资料缺失会说明未知；群等级不是王者段位，QQ展示的年龄等信息也不是核验的现实身份。

配置昵称、玩家键或精确别名可以用于查找 QQ。账号未配置自身 QQ 时，通过 `sameuser` 关联查找大号 QQ，参考查询的 `id_sources.qq` 会标明来源账号；已有 QQ 配置优先。同名对应不同 QQ 或关联冲突时需进一步确认目标。资料读取范围和权限仍由本次真实发送者及当前会话确定。

普通群只能读当前群的成员；管理员私聊可以在授权群里查。普通私聊没有群成员读取权限。本地网页暂时不能读取实时 QQ群成员资料和头像。

### 更换机器人头像

只有配置管理员可以在群聊或私聊中要求更换机器人的 QQ头像。发送图片并说“把这张图设为你的QQ头像”，或引用一张图片再提出更换要求；有多张图片时指定第几张，直接发送的图片先于引用图片。工具为 `set_bot_avatar`。

也可以要求“生成一张猫咪图片并直接设为你的QQ头像”，机器人先生成图片，再将本轮生成结果设为头像，无需重新发图。生成工具返回的 `image_resource_id` 用于换头像，不是产物的 `artifact_id`，且不能跨轮使用。

只能使用本次消息、引用中已经成功读取的图片，或本轮成功生成的图片；不支持任意图片链接、文件路径、历史图片或修改他人头像。没有输入图片时可以按用户要求生成，或请用户发送图片。生成失败、图片已过期或读取失败不会修改头像。成功结果表示 QQ接口确认提交，客户端缓存可能延迟刷新；接口超时不能保证已生效，也不会自动重复提交。普通用户和本地网页不提供此账号修改权限。
