# 战绩、排行与在线状态

### 个人战绩

使用 `#我的战绩` 查看今天的战报；`#我昨天的战绩` 查看昨天；`#昵称的战绩-8` 查看8天前；`#昵称的战绩7-14` 查看对应天数区间。

返回对局和胜负、评分、段位变化等信息，通常附战绩网页；有可用详情时也可收到最近一局的摘要和图片。已绑定客户端账号的玩家会并行读取营地及客户端普通/娱乐战绩，去重后保存并展示，补入营地没有的对局。客户端对局转换后保存到同一详情库，可在战绩网页中点击查看阵营、玩家、KDA、经济和伤害等已取得的数据。单方失败会保留另一来源及已保存记录，战报不附额外来源说明或重复列表。客户端独有对局尚未取得的评分和段位变化不当作0分参与统计。数据未收录、战绩不可见或请求过快时可能没有结果。

### 群体排行与巅峰排行

`#排行` 或 `#排名` 查看当日成员战绩榜单。`#巅峰排名` 或 `#巅峰排行` 查看已经收录的历史巅峰排名。历史榜单不能当成此刻的官方实时名次。

### 在线状态

`#在线` 查看已登记的王者玩家和已绑定 Steam玩家的状态；可以展示正在玩的游戏及对局信息。没有绑定或外部数据不可用的成员可能无法展示。

### 按条件查对局

例如 `#查询我和昵称一起玩的排位赛中我评分更高的对局`，按玩家、英雄、日期、模式、结果和表现等条件筛选历史战绩。一局结果可能附详情图，多局通常给列表链接。

在 AI 聊天里也可以直接要求统计和比较已收录战绩。需要官方实时查询或固定格式的业务操作时，优先使用对应的 #命令。

进一步说明：[历史战绩条件与单局、多局返回](history_query_rules.md)。

### 客户端直查

`#客户端 帮助` 查看独立客户端用法。`#客户端 主页 我`、`#客户端 战绩 example_user_10`、`#客户端 英雄 example_user_10 season` 分别查询主页、本次返回战绩和本赛季英雄。
英雄列表以所提供游戏截图为模板，按历史最高战力展示最多5个英雄，包含插画、名称、场次、胜率和历史最高战力，并注明展示数量，不显示英雄 ID。胜率数字按低于50%、50%至不足60%、不低于60%分别显示红、黄、绿；all / season / year 分别为全部比赛、本赛季和当前赛年。插画读取失败时明确占位，绘图失败时返回同一批英雄的简短文字。
也可使用资料、游戏统计（兼容统计）、资产、收藏、皮肤、英雄之路、称号；`#客户端 英雄详情 example_user_10 小乔` 支持配置中的完整英雄名和别名（例如卤蛋），也兼容 `#客户端 英雄详情 example_user_10 166`。`#客户端 英雄详情 小乔` 省略玩家时查询本人。未知或歧义名称会要求明确，不猜测英雄。
快捷模板同样要求 `#` 或 `＃` 前缀。`#示例玩家65的小乔` 先发送原有英雄统计，再附加 `#客户端 英雄详情 example_user_10 小乔` 的个人荣誉图片；`#示例玩家65的英雄` 保留原有汇总，再附加 `#客户端 英雄 example_user_10 season` 的统计图。原有汇总默认近30天，原有单英雄默认本赛季，显式“本赛季”继续按原范围处理。`#示例玩家65的数据` 对应 `#客户端 游戏统计 example_user_10`。玩家可用配置昵称、账号键或已登记的精确别名；“我”使用本次真实发送者绑定。`群u的英雄名` 和 `群u的英雄` 保留原有群体查询。
客户端文字结果统一提取有用字段并转成中文摘要，不直接显示 JSON 或协议字段。图片只保留界面字段，具体缺项在图外说明。游戏统计使用对战资料界面模板展示场次、胜率、奖牌、MVP和连杀；自然语言单英雄查询使用个人荣誉模板，保留原有文案；使用客户端原生显示值补充综合得分、五维雷达、赛年标签、历史徽章获得次数、战斗风格及分路段位；实际未返回的字段才用—占位，说明在图外；最近战绩确认本人视角后展示英雄、胜负、击杀/死亡/助攻和时间，并注明仅为本次返回。列表默认展示前5项。未提供或暂不支持的资料会说明缺失，不推断为0。客户端查询失败或未绑定不会取消已经发出的原有统计；显式 `#客户端` 只查询客户端资料。
`#客户端 搜索 完整游戏昵称 [all/android/ios]` 默认搜索 Android 与 iOS，返回候选，不自动绑定玩家。

省略玩家时使用真实 QQ 对应的唯一已绑定账号；有多个账号或同名时使用配置账号键。未绑定不会查询登录账号代替。
结果直接发送可读文字或图片，不使用聊天记录转发；超长会标记截断。接口受玩家隐私、会话有效期及服务端返回范围限制，战绩结束不代表全部历史。
适配层统一限速，默认至少间隔 10 秒、每分钟最多 5 次、每小时最多 120 次；达到额度或发生服务端冷却时按提示等待，无自动重试。

`#我的数据` 默认当前赛季、所有游戏、全部分路。可用 `#我的数据 当前赛年 中路`、`#示例玩家65的数据 全部比赛 所有游戏`、`#我当前赛季打野的数据`；“当前塞年”也兼容为当前赛年。具体分路支持对抗路、中路、发育路、打野、游走；可再指定排位、匹配、巅峰或娱乐（娱乐没有分路统计）。这是服务端累计统计，不按近期战绩重算。官方默认插画不代表玩家当前穿戴皮肤。
