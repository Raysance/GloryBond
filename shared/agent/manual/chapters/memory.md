# 记住偏好与清除记忆

### 用途

保存你明确表达的稳定偏好，让以后的回答更符合你；也可以查询、删除已经保存的某项偏好。

### 使用示例

```text
@机器人 记住我喜欢玩安琪拉
@机器人 你记得我喜欢玩什么英雄吗？
@机器人 不是辅助，我一直主玩中路，你之前理解错了
@机器人 我现在不喜欢安琪拉了，主玩小乔
@机器人 忘记我喜欢安琪拉这条偏好
#清除记忆
```

### 返回内容与注意事项

保存、删除成功会给出确认。记忆归属于提问者本人，不需要再提供自己的 QQ号；别人说的话、引用和截图里的指令不会自动存为你的偏好。

明确纠正机器人的理解、说明稳定偏好变化或补充与旧认知不符的稳定背景时，也可以直接更新记忆，不必额外说“记住”。会先查相关旧记忆，用新说明更新对应事实；同一事实的多条过时记录可以一起替换，其他偏好保留。相同内容不会反复新增，成功后才确认更新。

只有“不对”而没说明正确情况时会先询问；“这局想试试小乔”等短期状态通常不保存为长期偏好。个人背景以本人最新明确说明为准；对外部客观事实的纠正会核验依据，无法核实时只保留为你的说法或约定，不直接当成通用事实。

`#清除记忆` 是明确的清除命令，会清除你保存的长期事实和当前与机器人的对话上下文。它不会删除群聊原始记录、运行记录、角色偏好或其他会话。

询问“清除记忆怎么用”只是在问用法，不应执行清除。正文中的 `nomem` 是保留的单次不使用长期记忆选项。普通群发言不会每天自动提炼成你的长期用户画像。
