# 英雄胜率、常用英雄与样本门槛

个人 `#我的英雄` 保留原有对局聚合统计，再附加客户端返回的本赛季 按最高战力排序的前5张英雄卡片；`#我的英雄名` 保留原有单英雄统计，再附加客户端个人荣誉图片。两类来源的时间范围各自注明，不能混为同一口径。以下时间窗与样本门槛继续用于原有本地聚合、群体统计及相关业务接口。

常用英雄汇总按时间范围内已经收录的个人对局聚合。常用英雄汇总接口默认近30天、每榜前3个英雄，胜率和评分榜默认至少2场；本赛季或用户明确提出其他范围时应按该范围查询，而非把默认值当作所有接口的固定规则。

英雄胜率=已收录胜场/出场次数；平均评分只来自有真实评分的记录，客户端未知评分占位不参与计算；平均评分来自纳入记录的评分值，低场次榜单容易受单局影响。出场次数、击杀、死亡、助攻和MVP次数是不同口径，不要用官方个人资料的累计战力替代这一时间窗的战绩。

不同玩家/群体接口的最少场次和榜单长度可能不同。查看统计时应同时说明时间、样本数量和门槛。没有记录或战绩不可见不代表胜率0%；历史记录未完整收录时也不能把结果称为全赛季完整统计。
