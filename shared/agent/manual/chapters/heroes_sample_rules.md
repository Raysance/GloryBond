# 英雄胜率、常用英雄与样本门槛

个人 `#我的英雄` 使用客户端返回的本赛季 5v5 英雄统计，按场次选取前5个展示；`#我的英雄名` 进入客户端单英雄详情。以下已收录对局的时间窗与样本门槛用于原有本地聚合、群体统计及相关业务接口，不替代客户端数据口径。

常用英雄汇总按时间范围内已经收录的个人对局聚合。常用英雄汇总接口默认近30天、每榜前3个英雄，胜率和评分榜默认至少2场；本赛季或用户明确提出其他范围时应按该范围查询，而非把默认值当作所有接口的固定规则。

英雄胜率=已收录胜场/出场次数；平均评分来自纳入记录的评分值，低场次榜单容易受单局影响。出场次数、击杀、死亡、助攻和MVP次数是不同口径，不要用官方个人资料的累计战力替代这一时间窗的战绩。

不同玩家/群体接口的最少场次和榜单长度可能不同。查看统计时应同时说明时间、样本数量和门槛。没有记录或战绩不可见不代表胜率0%；历史记录未完整收录时也不能把结果称为全赛季完整统计。
