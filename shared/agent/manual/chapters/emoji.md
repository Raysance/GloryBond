# 表情包生成

### 用途与例子

按指定模板或你发的参考图生成表情包；可以写文字要求，也可以使用随机模板。

```text
#emoji
#emoji 001 震惊但嘴硬
#emoji template=奶龙 prompt=委屈地说我没事
#emoji 模板=E1_001 提示词=做一个开心贴纸
```

### 返回内容与注意事项

生成成功会返回图片。模板前缀保留前导0；指定模板要能在当前素材中找到。要用自己的参考图片，请在同一条消息中附图片并写 #emoji，图片和命令一起发送。未指定内容时可以结合当前群里本人的最近发言生成，其他群成员的发言不会冒充你的意思。

这项 QQ命令与“理解动态表情”是两种操作。本地网页可以让 AI 创作图片，但没有 QQ的 #emoji 模板命令。
