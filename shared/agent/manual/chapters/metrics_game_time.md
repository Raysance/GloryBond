# 游戏时长的范围与单位

#我的时长默认查看最近两周。个人时长和时长排行的王者部分均计入范围内所有已收录模式，包括共鸣之战、匹配及其他娱乐模式，不按正式对局筛选。统计把对局的持续秒数相加，再除以3600；这只计算对局时长，不包含大厅、排队或后台挂机时间。

Steam部分来自已绑定账号的最近两周游戏分钟数，除以60换算为小时。未绑定、未配置访问凭据或不可读取时不能提供完整Steam时长。仅显示有时长的游戏，单人展示通常保留1位小数。

总时长将王者和Steam的游戏时长相加，不能据此推断真实在线时长或排除多设备同时运行的重叠时间。群体排行只涵盖已配置且有可用记录的玩家；存在同人账号映射时汇总为同一人。
