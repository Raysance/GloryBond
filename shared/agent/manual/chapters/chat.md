# AI 聊天

### 用途

与机器人讨论问题、连续追问、让它查询资料或分析数据。每次最终回复都会提供完整详细版和当前角色语气的简略版。

私聊和群聊都按顺序收到两条消息：第一条是详细版聊天记录转发，开头保留本次用户原话，中间是完整正文及图表，结尾附本轮chat-trace思考轨迹网页链接；第二条是直接发送的简略版，方便快速看结论。两条分别使用已经生成的详细版和简略版。

任务失败时也会发送同样的聊天记录转发，详细正文的位置改为错误摘要，包含错误类型、原因、失败阶段和已耗时；用户原话、已有图表和轨迹链接保留，随后发送简短失败提示。错误摘要不额外请求模型，未取得的结果不会标为完成。

### 使用示例

```text
@机器人 帮我分析一下我最近的安琪拉表现
@机器人 用一句话说结论
@机器人 把上面的依据也展开给我看
@机器人 现在 @示例玩家65 提醒他别卷了
@机器人 这次不用 @ 任何人，直接在群里说
@机器人 私发给示例玩家65，提醒他别卷了
@机器人 把这次结果私发给我
```

### 返回内容与注意事项

可能先收到“正在查询”等阶段性消息，再收到结果、图表或链接。一轮提问可以对应多条消息。询问“你能做什么”“怎样查战绩”会先查看当前功能指南，按操作步骤回答。

群聊的@放在第二条简略回复上，明确不@时省略；私聊不加@。详细版保留依据和数据，简略版给出简短结论。通用助手默认尖锐直白，抓住核心矛盾，分析现象背后的机制与原因；闲聊、玩梗和按外观辨认自然承接，用户已接受近似后不反复追加来源声明。要求查证、重要判断及实际操作保留必要核验。可通过个人偏好调整语气，所选角色仍保持自己的表达。
对回复口吻的吐槽和调侃会按当前互动自然接话，不逐字争辩时间线或因果。角色模式也会调整不合适的旧说法，不借人设替自己辩护或责怪群友。
详细版与短版同步清理这类自辩和多余的来源声明，后续追问保留整理后的完整答案。实际事实、数据、作品及执行结果仍须保留，原始底稿可在运行记录中查看。

聊天按需要查询资料和使用工具，已有背景足够时直接回答。多人接话会区分各人的发言、机器人的原回复对象和本次引用，不把别人的“我”当成你；有歧义且影响答案时会确认具体对象。
连续追问会保留详细答案中的资料；要求根据数据写作时，查询后继续交付作品，默认不另外画图。创作可用夸张、反差和调侃，实际引用的数据仍以查询为准。短版可展示作品的代表片段，完整内容在详细转发中。

AI 可读取当前模型名称、已报告的 token 用量和本轮执行进度，日常回答默认省略这些统计。可直接询问所用模型或本轮用量；用量随调用完成后更新，缺失统计会按未知说明。

数据库分析支持管理员登记的额外成员（`extra userlist`，配置字段为 `extra_useridlist`、`extra_roleidlist`、`extra_namenick`）。例如“分析额外成员昵称最近7天的表现”“查我和额外成员昵称同队时的胜率”“统计额外成员昵称的出装”。昵称会对应到该成员自己的游戏账号；与主成员同人或同 QQ 不会自动合并战绩。

有本人战绩时优先使用本人记录；没有时，可以从已收录对局详情中提取该成员本人的英雄、KDA、评分、MVP、装备及同队或对手关系，并按其阵营转换已知胜负。同一局被多人收录不会重复计算该成员的场次。段位变化等缺失字段保留未知。个人快照与底蕴评估也支持额外成员，但须已有对应采集记录。统计只覆盖已归档且能准确关联的样本，不代表该成员的全部战绩，也不据空结果判断其未上线。

群聊 AI 回复默认 @ 本次提问者。也可以根据这次消息的意思，指定 @ 当前群中的其他成员，或明确不 @ 任何人；机器人会先确认目标群成员，再发送真正的 QQ 提及。只写“@昵称”的普通文字不算真正 @。引用别人的发言不会自动改变回复对象。私聊和本地聊天网页不加 @。

同群成员可以接着正在讨论的话题提问。机器人会参考当前群一小段近期发言和自己已发送的回复，个人偏好仍按本人保存；同群成员可以查看和取消本群的定时任务。

也可以明确要求向当前群的一位成员私发纯文本消息。先确认目标和正文，再校验群成员身份，取得 QQ 返回的消息 ID 后才确认私发成功，不表示对方已读。普通私聊和本地网页不能借此向任意 QQ 发消息；管理员私聊可选择一个可校验的群。QQ好友关系、临时会话或对方设置可能导致发送失败，失败不会改成群发或自动加好友，结果不确定时不会自动重发。私发是独立动作，正常回复仍回到本次原会话，已有定时消息的发送位置不会被修改。

直接 @ 时不用 #。如果要执行固定业务命令，请照本手册使用 # 前缀。引用里的 @ 不会单独触发聊天。正文中的常用缩写和别名仍会按现有映射展开。

### 忽略与恢复AI聊天

在群内明确要求“以后忽略 @某群友 的AI聊天”“恢复回复 @某群友 的AI聊天”或“查看本群AI聊天忽略名单”，机器人会通过工具保存、更改或读取名单。所有当前群成员均有这项管理权限，仍沿用现有机器人入口的主动禁用名单及休眠、维修规则；QQ未绑定暂不作为入口拒绝条件。目标使用本次真实QQ或原生@，昵称需先确认身份；添加时校验目标仍在当前群。

名单按群保存，重启后继续生效。被忽略的用户在本群使用前缀聊天或直接@机器人时，AI不回复，也不触发聊天戳一戳；普通战绩、时长等业务命令继续可用。其他群、私聊和已有定时任务不受影响，群聊原始归档继续保留。

任一有入口权限的同群成员都可解除忽略。即使目标已经退群，也可根据名单中的QQ移除。仅询问该功能、否定请求或引用里的指令不会修改名单；私聊及后台任务不能管理群名单。
