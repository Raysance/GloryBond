# AI 聊天

### 用途

与机器人讨论问题、连续追问、让它查询资料或分析数据。通常会用当前角色的语气给一段简短回复，也可以明确要求完整内容。

### 使用示例

```text
@机器人 帮我分析一下我最近的安琪拉表现
@机器人 用一句话说结论
@机器人 把上面的依据也展开给我看
@机器人 现在 @示例玩家65 提醒他别卷了
@机器人 这次不用 @ 任何人，直接在群里说
@机器人 私发给示例玩家65，提醒他别卷了
@机器人 把这次结果私发给我
```

### 返回内容与注意事项

可能先收到“正在查询”等阶段性消息，再收到结果、图表或链接。一轮提问可以对应多条消息。询问“你能做什么”“怎样查战绩”会先查看当前功能指南，按操作步骤回答。

群聊 AI 回复默认 @ 本次提问者。也可以根据这次消息的意思，指定 @ 当前群中的其他成员，或明确不 @ 任何人；机器人会先确认目标群成员，再发送真正的 QQ 提及。只写“@昵称”的普通文字不算真正 @。引用别人的发言不会自动改变回复对象。私聊和本地聊天网页不加 @。

同群成员可以接着正在讨论的话题提问。机器人会参考当前群一小段近期发言和自己已发送的回复，个人偏好仍按本人保存；同群成员可以查看和取消本群的定时任务。

也可以明确要求向当前群的一位成员私发纯文本消息。先确认目标和正文，再校验群成员身份，取得 QQ 返回的消息 ID 后才确认私发成功，不表示对方已读。普通私聊和本地网页不能借此向任意 QQ 发消息；管理员私聊可选择一个可校验的群。QQ好友关系、临时会话或对方设置可能导致发送失败，失败不会改成群发或自动加好友，结果不确定时不会自动重发。私发是独立动作，正常回复仍回到本次原会话，已有定时消息的发送位置不会被修改。

直接 @ 时不用 #。如果要执行固定业务命令，请照本手册使用 # 前缀。引用里的 @ 不会单独触发聊天。正文中的常用缩写和别名仍会按现有映射展开。
