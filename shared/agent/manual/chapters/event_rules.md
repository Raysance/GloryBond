# 条件触发提醒与动作

在群里用 `@机器人` 或 `#` 发起请求，例如“以后群里有人说到开黑时提醒我”“推送某个已订阅UP的新视频时在原消息里@我”“X订阅的@example更新时@我”“有人提到比赛结果时，查我的当天战报并回复”。不要求固定句式。

这类规则在消息到来时触发。具体几点、多久后的提醒仍使用定时任务。

条件支持消息中包含任一或全部关键词、指定QQ发送者，以及机器人消息的业务来源。关键词忽略大小写，按可见文字字面匹配，不自动理解图片、视频或转发附件内容。多个条件字段同时满足才触发。B站规则可以指定已订阅UP的完整名称或已确认mid，X规则指定已订阅账号的@username或已确认数字ID，实际绑定稳定作者ID；只能在配置的推送群管理，不会自动新增内容订阅。X关键词匹配消息中的文字预览，不自动读取图片卡片里的完整正文。

按昵称指定发送者时，保存工具通过 `condition.sender_name` 接收配置中的玩家键、昵称或精确别名，并在服务器绑定实际 QQ。该账号未配置 QQ 时，沿 `sameuser` 找到大号的 QQ；已有自身 QQ 的账号优先使用自身配置。例如“示例玩家34”对应 `example_user_7`，由 `sameuser.example_user_2` 找到大号 `example_user_2` 的 QQ。昵称重名且对应不同 QQ、关联冲突或缺失时需补充明确 QQ。昵称与同时传入的 QQ 不一致会返回核对提示。规则最终保存稳定的 `sender_id`，后续按消息的真实发送者匹配，配置昵称变化不改变已有规则。

动作支持在群里@规则创建者并发送固定提醒、发送固定文字、执行已授权的查询/分析/绘图任务，以及在普通机器人消息发送前追加创建者的原生@。私聊规则只作用于本人的私聊，群规则只作用于创建时所在群。复杂任务使用规则创建者的当前权限，触发消息仅作参考资料；不能借触发内容创建更多规则、定时任务、改头像或向其他会话发送消息。

要让B站或X原推送直接带@，可以说“以后推送这个UP的视频时，在原消息里@我”或“X的@example发新帖推送时，在原消息里@我”。如果选择“发出后提醒我”，机器人会另发一条提醒。原消息追加@适用于普通群消息；合并转发可以在发送后触发提醒。多个用户命中同一条原推送时会合并提及对象。

可以要求“查看我在这个群设置的规则”“暂停刚才的开黑提醒”“把规则改成只触发一次”“删除我的这条提醒”。修改或删除会先查询本人的规则确认对象，不能修改他人的规则。保存后返回实际条件、动作和规则ID，成功保存不代表动作已经执行。

默认冷却300秒，可以明确要求其他冷却时间；支持触发次数上限和有效期。默认每人每个会话最多20条、每个会话最多100条规则。新规则跳过创建消息和本轮确认回复，只匹配保存后的新消息。休眠、维修、禁用与QQ白名单继续生效，群动作执行时重新确认创建者仍为群成员。

机器人普通回复和自动推送也参与匹配。规则产生的消息携带触发链，同一规则不能在同一条链内反复执行；默认最多2层、同一源事件最多10个动作。已领取、已经入队或结果未知的动作不会自动重发。删除或暂停会阻止后续触发及尚未开始的执行；已经提交的消息或已经开始的外部操作可能仍会完成。

规则及待执行动作跨重启保存。可以查询最近执行状态；queued表示已入队，sent表示QQ已返回消息ID，completed表示动作处理完成，unknown表示未能确认结果，不等于发送成功。机器人离线、存储故障期间收到的事件不保证补发。
