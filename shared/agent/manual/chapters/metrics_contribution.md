# 正式评分与团队贡献系数

正式评分平均值只使用排位、巅峰、战队等正式对局，排除1v1/2v2/3v3，取这些对局评分的算术平均，展示保留3位小数。其他分析页面可能使用不同的模式筛选，比较前先确认样本。

单局团队贡献系数 = (5×个人评分/本方总评分) × (5×个人经济/本方总经济)^(-0.5)。若最终装备命中学识宝石、近卫或极影，经济比值项先除以0.9，再计算负0.5次方。

该指标将评分份额和经济占用结合：在评分相同的条件下，较低的经济份额可能得到更高系数。它不是官方MVP判定，也不是伤害占比。

找不到本人/阵营、团队总评分或经济为0、本人经济为0时没有有效系数。历史贡献平均值只纳入正式对局中能读取详情且能计算的样本，不把缺失详情当作0分场次。
