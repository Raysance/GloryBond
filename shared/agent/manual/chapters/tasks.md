# 定时提醒与多次消息

### 用途

延迟发送提醒、按周期发送指定次数，或者定时查询后给你结果。

### 使用示例

```text
@机器人 10分钟后提醒我休息
@机器人 每隔10秒给我发一条消息，发三次
@机器人 每小时查一次指定话题的最新消息，共查两次
@机器人 看看我在这个会话里安排的任务
@机器人 取消刚才的提醒任务
```

### 返回内容与注意事项

先收到创建结果，再在约定时间收到消息。固定文字提醒与需要查询的任务都可安排；支持的最短周期为1秒。未指定首次延迟的周期任务会等待一个周期后开始。

任务发往创建时绑定的当前会话，不能让它偷偷改发给其他人。取消应以成功结果为准。服务停止时不会按时执行；恢复后错过的时间点不会集中补发，异常重启也不能保证通知绝不重复。本地网页任务需要本地服务运行。

同一次提问也可以分批回答，无需创建定时任务。信息较多、多个问题、详细步骤或对象对比时，可以先收到结论，再收到依据和后续步骤；也可以直接说“内容多的话分几条发，讲清楚就行”。每条按完整意思组织，保持角色语气与个人偏好，避免逐句刷屏；用户要求一条或简短时优先遵守。已发送的正文不会在最终回复中整段重发，并与最后一条回复一起保存在当前会话上下文中，便于追问。分批是否发生由模型结合问题判断，并非每个回答都会拆分。
