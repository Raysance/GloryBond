# 底蕴统计的样本与排行口径

#我的底蕴默认查询最近7天。正式对局口径包含排位、巅峰和战队赛，排除1v1/2v2/3v3；不是所有娱乐模式都参加。

只统计已经保存底蕴评估、且能够定位本人记录的对局。未评估的正式对局会单独提示待评估数量，不会用0补进有效样本。胜率也按这一批已评估样本计算，可能与全部战绩胜率不同。

单局我方/对方底蕴是该侧有效授权玩家的个人底蕴之和。近期统计的我方、对方、差值和个人底蕴分别对有效对局取算术平均。

“个人底蕴/队友对手底蕴”先在每局计算本人底蕴÷该局底蕴大于0的所有玩家平均底蕴×100%，再对各局取平均。这个100%基准是有效玩家平均值，不能与单局图卡以最高玩家为100%的显示混用。

底蕴排行按每局(己方团队底蕴+对方团队底蕴)/2的跨局平均值降序排列；不是按个人单人底蕴排序。榜内同时展示个人及双方指标，必须看清列名和有效场次。
