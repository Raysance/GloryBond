# 英雄表现、梯度与荣耀战力

### 英雄表现

| 想查询什么 | 示例 |
| --- | --- |
| 自己的一个英雄 | #我的安琪拉 |
| 自己的常用英雄 | #我的英雄 |
| 自己的游戏统计 | #我的数据 |
| 群成员使用同一英雄的表现 | #群u的安琪拉 |
| 群成员整体英雄情况 | #群u的英雄 |
| 本赛季常用英雄 | #我本赛季的英雄 |

个人模板先返回原有统计，再补充客户端资料。`#我的安琪拉` 保留原有战绩表现等内容，随后附加按游戏个人荣誉界面模板生成的图片；`#我的英雄` 保留原有英雄汇总与排行，随后展示客户端本赛季按最高战力排序的前5张英雄卡片。原有汇总默认近30天，显式“本赛季”按原范围处理；客户端统计图含插画、场次、胜率和最高战力，胜率按红、黄、绿区分高低。客户端暂不可用时，原有统计仍保留。

`#我的数据` 查询客户端游戏统计，默认生成当前赛季全部分路的对战资料图片，支持当前赛年、全部比赛及具体分路关键词，不显示原始 JSON，也不使用合并转发。已接入原生评分、雷达、标签、历史徽章、战斗风格和分路段位；确实未取得的字段才占位，并在图外说明；插画使用官方默认形象。也可将“我”替换为配置中的玩家昵称或别名。范围和完整命令见[客户端直查](games.md#客户端直查)。

`群u` 表示机器人已登记的玩家集合，继续使用原群体统计。根据查询类型，返回场次、胜率、MVP、评分、近期表现或榜单，可明确带“本赛季”。

### 今日英雄

`#今日英雄` 获取自己的今日推荐，通常包含英雄、相关资料、推荐理由或图片。它默认针对本人，不要用“昵称的今日英雄”查询他人。每天的推荐会保留当日结果。

### 英雄梯度与战力

`#梯度` 查看英雄梯度长图。`#我的战力` 查看自己的高战力英雄及相关名次；`#战力查询 不知火舞 武侯区` 查看指定英雄在指定地区的荣耀战力榜信息，英雄和地区顺序不限。

地区或英雄无法识别时会要求确认；榜单与梯度可能受数据更新和外部服务影响。荣耀战力数值、梯度评价和你个人的胜率是不同信息。

进一步说明：[英雄胜率、常用英雄与样本门槛](heroes_sample_rules.md)。
