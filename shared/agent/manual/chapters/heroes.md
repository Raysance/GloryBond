# 英雄表现、梯度与荣耀战力

### 英雄表现

| 想查询什么 | 示例 |
| --- | --- |
| 自己的一个英雄 | #我的安琪拉 |
| 自己的常用英雄 | #我的英雄 |
| 群成员使用同一英雄的表现 | #群u的安琪拉 |
| 群成员整体英雄情况 | #群u的英雄 |
| 本赛季常用英雄 | #我本赛季的英雄 |

`群u` 表示机器人已登记的玩家集合。根据查询类型，返回场次、胜率、MVP、评分、近期表现或榜单。单人单英雄查询使用当前赛季的资料；其他汇总可明确带“本赛季”。

### 今日英雄

`#今日英雄` 获取自己的今日推荐，通常包含英雄、相关资料、推荐理由或图片。它默认针对本人，不要用“昵称的今日英雄”查询他人。每天的推荐会保留当日结果。

### 英雄梯度与战力

`#梯度` 查看英雄梯度长图。`#我的战力` 查看自己的高战力英雄及相关名次；`#战力查询 不知火舞 武侯区` 查看指定英雄在指定地区的荣耀战力榜信息，英雄和地区顺序不限。

地区或英雄无法识别时会要求确认；榜单与梯度可能受数据更新和外部服务影响。荣耀战力数值、梯度评价和你个人的胜率是不同信息。

进一步说明：[英雄胜率、常用英雄与样本门槛](heroes_sample_rules.md)。

### 皮肤返场排行

`#皮肤返场` 查询皮肤返场投票排行，也支持 `#返场排行`、`#返场排名`、`#皮肤返场排行`、`#皮肤返场排名`、`#皮肤返场查询`，井号可使用全角 `＃`。命令完整匹配，沿用 QQ 白名单、禁用、休眠与维修检查。

默认文字列出前 5 名的英雄、皮肤和累计票数，随后附一张前 10 名的近 6 小时趋势与排行图片。图片包含缩略图、累计票数、区间增长、分均票数及与上一名的票差，采用网页的白底、细边框和彩色趋势线。时间按北京时间显示实际数据更新时间，不以查询时间冒充更新。回复文字和图片均不标注数据来源或网址。

数据接口为天元之弈的 `/api/skin-votes/trend`，属于第三方收录；票数存在约百票精度误差，分均为估算值，不能当成官方实时结果。区间增长从每款皮肤首个有效观测计算，缺失记录保留空白。默认范围、文字/图片名次数、超时及字体集中在 `config.yaml#SkinVotes`，可选时间范围为 6、12、24、72 小时，0 为全部记录。

查询只读，不投票、不创建订阅。暂无数据时明确说明；图片或缩略图失败仍保留文字榜单，图片故障带定位提示。该功能为前缀命令 handler，尚未注册为 QQ AI 业务函数。
