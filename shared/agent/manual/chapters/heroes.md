# 英雄表现、梯度与荣耀战力

### 英雄表现

| 想查询什么 | 示例 |
| --- | --- |
| 自己的一个英雄 | #我的安琪拉 |
| 自己的常用英雄 | #我的英雄 |
| 群成员使用同一英雄的表现 | #群u的安琪拉 |
| 群成员整体英雄情况 | #群u的英雄 |
| 本赛季常用英雄 | #我本赛季的英雄 |

`群u` 表示机器人已登记的玩家集合。根据查询类型，返回场次、胜率、MVP、评分、近期表现或榜单。单人单英雄查询使用当前赛季的资料；其他汇总可明确带“本赛季”。

### 今日英雄

`#今日英雄` 获取自己的今日推荐，通常包含英雄、相关资料、推荐理由或图片。它默认针对本人，不要用“昵称的今日英雄”查询他人。每天的推荐会保留当日结果。

### 英雄梯度与战力

`#梯度` 查看英雄梯度长图。`#我的战力` 查看自己的高战力英雄及相关名次；`#战力查询 不知火舞 武侯区` 查看指定英雄在指定地区的荣耀战力榜信息，英雄和地区顺序不限。

地区或英雄无法识别时会要求确认；榜单与梯度可能受数据更新和外部服务影响。荣耀战力数值、梯度评价和你个人的胜率是不同信息。

进一步说明：[英雄胜率、常用英雄与样本门槛](heroes_sample_rules.md)。
