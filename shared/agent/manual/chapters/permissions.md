# 使用范围

- QQ使用可能需要先由管理员登记你的 QQ号及游戏账号；账号未登记、功能被禁用、休眠或维修时，机器人可能提示无法使用。
- 群内 AI请求只读取当前群的发言和群成员资料，即使管理员在群里提问也是如此。
- 管理员私聊可以查授权群；未指定群时采用设置的默认群。普通私聊不能读取群聊或群成员资料。
- 查询范围不会改变消息的接收位置：在私聊安排的任务仍发到该私聊。
- 只有明确要求时，QQ群聊可私发纯文本给经校验的当前群成员；管理员私聊可选择一个群校验目标，普通私聊和本地网页不提供此发送工具。这是独立动作，不改变正常回复或已有任务的发送位置，也不授予读取对方私人记忆的权限。
- 本地网页能进行聊天、查资料、数据分析、作图、图片生成、角色和提醒操作；实时 QQ资料、戳一戳及 #业务命令仍是 QQ专属操作。
