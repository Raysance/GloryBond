# 创作图片的服务、模型与返回方式

创作图片使用APIMart的图片生成服务，公开接口为 https://api.apimart.ai/v1/images/generations 。当前配置初始模型为gpt-image-2，实际模型可由运行设置调整；这是生图服务，与负责文字聊天和图片理解的DeepSeek V4.1 Flash不同。

AI聊天的生成工具每次请求1张图，默认比例1:1、分辨率1K，可提出画面内容和比例要求。服务先返回任务，再等待生成完成并读取图片；失败、取消或超时不会被当作生成成功，通常耗时比文字回复长。

通用AI生图工具当前提交文字提示词，没有把本次聊天图片自动传成参考图。QQ的#emoji参考图/模板命令有单独的参考图片流程，不要把两项能力混为一谈。

图片生成需要服务可用且凭据配置正确，不能在回答中展示密钥。统计绘图使用查到的数据计算并渲染，不通过这个生图API伪造数据图；生成的画面也不是事实查询证据。
