# 群聊背景查询

### 用途

找到之前的相关发言，或者在“刚才说的那个”“他们在聊什么”等问题缺少背景时，补读一小段近期群聊。

### 使用示例

```text
@机器人 刚才大家在聊什么？
@机器人 找一下昨天有人讨论安琪拉的发言
@机器人 看看群里最近15分钟是谁说缺辅助
```

### 返回内容与注意事项

会返回相关发言或背景解释。最近发言默认最多20条，必要时可增加到最多50条，不限制时间跨度；会包含不同发言者，并提示摘录是否截断。搜索命中的条数不等于整个群的话题总次数。指定日期或时间范围的问题可通过群聊查询按要求筛选。

你的直接追问会参考你与机器人的近期对话。群聊接话还会自动参考当前群最新的最多20条公共背景，不限制时间跨度，包括不同成员的发言及机器人已入发送队列的回复摘录；更早的内容可继续查询。不同成员可以接着同一话题说话，个人偏好仍按本人区分；同群成员可查看和取消本群定时任务。引用和查出的群聊内容不会被当成你的个人偏好。普通群内只查当前群，管理员私聊的范围见“使用范围”。
