# 查看完整回复与运行记录

### 怎么用

QQ每次最终回复都会发两条：先发送详细版聊天记录转发，再直接发送简略版，私聊和群聊一致。详细转发开头是本次用户原话，中间是完整正文和图表，最后一条是本轮chat-trace思考轨迹网页链接。第二条方便快速看结论，群聊的@放在简略版上。想继续展开某一部分时，可以说“把上面的依据展开”“给我完整结果”。

转发末条的chat-trace链接复用已经留存的本轮运行记录，管理员登录后可打开查看。也可以进入 Web 控制台的“AI 运行记录”，按时间查看、搜索问题摘要或 QQ、筛选群号与状态，再打开完整轨迹调试；记录默认保留7天、最多1000条。简略回复保持正文和图表，普通来源链接不受影响。本地网页可以切换查看详细内容与群聊回复，也可以展开执行过程和查看 token用量。

### 会看到什么

详细版保留依据、数据和来源；执行过程可以展示实际工具调用、结果和错误。token用量是接口报告的统计，未知或未完成的用量会说明。只有接口实际返回的思考字段才会展示，不会制造思考过程。

记录可以帮助调试，但查看功能指南不会把聊天日志或原始图片读出来。群聊归档和 AI对话记录是两回事；在本地网页聊天不会被伪装成 QQ群里的原始发言。
