# 代表局的筛选与三类指数

代表局按可用候选计算高光、糟糕、极端三类指数，不是让AI凭印象选比赛。当前基础筛选要求有可定位的比赛标识、结果为胜利或失败、评分0至20、时长300至7200秒；其他范围和权重随项目规则更新。

各因素先将实际值映射成0至1的比例，再乘对应权重，累计得到各类别指数。可能涉及绝对/相对评分、团队比较、连续击杀、死亡、表现与胜负反差、时长等因素；缺少详情的因素不能凭空补齐。指数用于挑选本批样本的代表比赛，并非官方评分或胜率。

省略日期默认今天。当天没有符合条件的候选会说明；不是每个玩家都一定获得一局。正式回复展示代表局文字、图片和点评；完整计算调试仅供管理员调试入口，不附在普通查询中。
