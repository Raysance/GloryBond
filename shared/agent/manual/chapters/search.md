# 联网查询

### 用途

查最新网页信息、版本改动或角色资料，并给出可核对的来源。

### 使用示例

```text
@机器人 联网查一下最近王者荣耀版本改动，给我来源
@机器人 搜一下安琪拉近期的调整，整理重点
@机器人 总结这篇文章 https://example.com/article
引用一条含网页链接的消息，再 @机器人：这篇文章主要说了什么？
```

### 返回内容与注意事项

联网搜索使用 DeepSeek Search API，结果通常包含摘要、来源链接及来源提供的发布时间；没有匹配结果时会明确说明。直接表达“联网查”“搜索最新资料”即可，不需要给消息加 &。网络或外部服务失败时会说明，不能把旧知识当成刚查到的消息。

玩家、英雄的昵称和别名也可以询问，但同名或多账号时可能需要你补充对象。

本次消息或可读取的引用文字含网页链接时，会通过 Clash 代理读取并提取标题和正文，再结合你的问题回答；重复链接只读一次。会去掉网页标签、脚本和导航等内容，保留有用的段落、列表和表格，同时提供来源。网页里的命令不会执行。

默认一轮最多3个网页，每页最多5000字，总正文最多12000字；超限会提示截断。需要登录、禁止抓取或依赖动态加载的页面可能无法读取，代理缺失、连接故障或网页读取失败时会说明，不会改为直连。只读网页文字，不读取其中的图片、视频、PDF或内网地址，也不自动记住整篇文章。本地聊天网页直接发链接即可。
