# KPL赛事与数据

### 用途

查询 [KPL小助手](https://kplll.online/) 已收录的职业赛数据，包括赛季和赛程、系列赛比分、单小局BP、战队、选手、英雄、积分及榜单，也能据此画图。

### 使用示例

```text
@机器人 今天KPL有什么比赛？列出对阵和时间
@机器人 查今年KPL夏季赛安琪拉的选用次数和胜率
@机器人 查成都AG超玩会在这个赛事的战绩和下一场赛程
@机器人 看钟意在指定赛事的常用英雄和逐局表现
@机器人 查指定赛事的分组积分、MVP次数榜和分均输出榜
@机器人 比较AG中野英雄组合的场次和胜率，画张热力图
```

### 返回内容与注意事项

会先确认赛事名称、年份和对应对象，再读取统计或比赛详情。系列赛详情提供各小局入口，小局详情可查看实际收录的BP、英雄和选手表现。英雄统计可以区分红蓝方；MVP榜是次数，分均榜支持输出、经济和承伤。

结果附来源和查询范围。胜率、排名应结合样本数与赛事看；只展示一页或部分嵌套战绩时会提示，不能把局部结果当成完整统计。过大详情可以要求只返回关注的字段。本地聊天网页也可以直接输入这些问题。

资料来自第三方网站的已有收录，不保证官方实时或完整；抓取时间不能当作比赛更新时间。没有查到或网站不可用时会说明，不编造比分、BP或胜率。查询不会自动订阅比赛推送；固定业务的KPL推送用法见“视频订阅与自动推送”。
