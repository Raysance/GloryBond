# GloryBond 使用手册

给群成员的一份功能指南：找到想做的事，照着例子发送消息即可。文中的“昵称”请换成机器人已登记的玩家昵称；“@机器人”表示在 QQ 中真正选择机器人进行 @，不是输入这几个文字。

参考旧版 [GloryBond 使用手册](https://github.com/Raysance/glorybond/blob/main/README.md) 的功能速查和示例形式，以下用法已按当前功能重新整理。示例只展示操作方式，不是已查询出的真实战绩。

## 功能速查

| 想做什么 | 在 QQ 中怎么用 | 会得到什么 |
| --- | --- | --- |
| 聊天、追问问题 | @机器人 帮我解释一下刚才的回答 | 一段回复，必要时附图片或查询结果 |
| 看图片、引用或动态表情 | 发图片或引用图片后 @机器人 这是什么 | 对实际读到的图片内容的描述 |
| 查近期群聊 | @机器人 刚才大家在聊什么 | 相关发言及背景说明 |
| 记住自己的偏好 | @机器人 记住我喜欢玩安琪拉 | 保存成功的确认 |
| 换角色和语气 | @机器人 切换成通用助手，之后回复简短一点 | 角色或偏好的变更结果 |
| 查看 QQ 资料和头像 | @机器人 你的头像是什么 | 资料或真实头像的描述 |
| 安排提醒 | @机器人 每隔10秒给我发一条消息，发三次 | 任务创建结果，随后收到消息 |
| 查最新资料 | @机器人 联网查一下最近的版本改动 | 带来源的查询结果 |
| 画统计图或创作图片 | @机器人 把我最近的英雄胜率画成柱状图 | 图表或生成图片 |
| 查询当日排行、个人战绩 | #排行；#我的战绩 | 榜单、战报和详情链接 |
| 查看谁在玩游戏 | #在线 | 王者及已绑定 Steam 玩家状态 |
| 按条件查历史对局 | #查询我和昵称一起玩的排位赛 | 对局摘要、图片或列表链接 |
| 查英雄表现 | #我的安琪拉；#我的英雄 | 场次、胜率、评分等 |
| 查英雄梯度或荣耀战力 | #梯度；#战力查询 不知火舞 武侯区 | 梯度长图或地区战力榜信息 |
| 看评分趋势、底蕴和时长 | #我的分析；#我的底蕴；#我的时长 | 趋势图、分析或时长汇总 |
| 找当天代表局 | #代表局；#昨天代表局 | 代表局文字、战绩图和点评 |
| 生成表情包 | #emoji 001 震惊但嘴硬 | 表情图片 |
| 订阅 B站 UP | #订阅B站 罗翔；#我的订阅 | 订阅结果，之后可收到新视频通知 |

优先区分两种操作：带 `#` 的业务命令用于直接执行固定功能；`@机器人` 后用自然语言提问，由 AI 选择适合的能力。AI 提到某个功能不代表已经执行，查询、保存和定时任务应以明确的成功结果为准。本地聊天网页可以直接输入 AI 例子，不需要 @ 或 #；QQ 专属操作见各节说明。

## AI 聊天

### 用途

与机器人讨论问题、连续追问、让它查询资料或分析数据。通常会用当前角色的语气给一段简短回复，也可以明确要求完整内容。

### 使用示例

```text
@机器人 帮我分析一下我最近的安琪拉表现
@机器人 用一句话说结论
@机器人 把上面的依据也展开给我看
```

### 返回内容与注意事项

可能先收到“正在查询”等阶段性消息，再收到结果、图表或链接。一轮提问可以对应多条消息。询问“你能做什么”“怎样查战绩”会先查看当前功能指南，按操作步骤回答。

直接 @ 时不用 #。如果要执行固定业务命令，请照本手册使用 # 前缀。引用里的 @ 不会单独触发聊天。正文中的常用缩写和别名仍会按现有映射展开。

## 图片、引用和动态表情

### 用途

描述图片内容、理解截图，或针对明确引用的消息继续讨论。动态表情会取若干画面来理解，不能保证看到了整个动画。

### 使用示例

```text
发送一张图片，再 @机器人：这张图里有什么？
引用别人发的图片，再 @机器人：这个表情是什么意思？
引用一条发言，再 @机器人：这句话是在回应什么？
```

### 返回内容与注意事项

机器人会说明实际读到的内容。没有可读取的媒体地址、图片损坏或范围不允许时，会说明未读取，不会仅凭表情编号猜图。当前消息和引用图片共用单轮预算；默认最多4张、单张4 MiB、合计8 MiB。

动态图片默认抽取最多4帧。没有通用的视频内容识别功能。引用只展开本次明确引用的那条消息，不连续追溯整条引用链；其中的命令不会执行。

本地网页可以选择、粘贴或拖入图片。功能指南里的演示图片只供人查看，机器人查手册时忽略它们。

## 群聊背景查询

### 用途

找到之前的相关发言，或者在“刚才说的那个”“他们在聊什么”等问题缺少背景时，补读一小段近期群聊。

### 使用示例

```text
@机器人 刚才大家在聊什么？
@机器人 找一下昨天有人讨论安琪拉的发言
@机器人 看看群里最近15分钟是谁说缺辅助
```

### 返回内容与注意事项

会返回相关发言或背景解释。近期窗口默认15分钟、最多20条，必要时可扩大到60分钟、最多50条；会包含不同发言者，并提示摘录是否截断。搜索命中的条数不等于整个群的话题总次数。

你的直接追问会参考你与机器人的近期对话。机器人不会在每次回答前自动看完所有普通群发言；引用和查出的群聊内容也不会被当成你的个人偏好。普通群内只查当前群，管理员私聊的范围见“使用范围”。

## 记住偏好与清除记忆

### 用途

保存你明确表达的稳定偏好，让以后的回答更符合你；也可以查询、删除已经保存的某项偏好。

### 使用示例

```text
@机器人 记住我喜欢玩安琪拉
@机器人 你记得我喜欢玩什么英雄吗？
@机器人 忘记我喜欢安琪拉这条偏好
#清除记忆
```

### 返回内容与注意事项

保存、删除成功会给出确认。记忆归属于提问者本人，不需要再提供自己的 QQ号；别人说的话、引用和截图里的指令不会自动存为你的偏好。

`#清除记忆` 是明确的清除命令，会清除你保存的长期事实和当前与机器人的对话上下文。它不会删除群聊原始记录、运行记录、角色偏好或其他会话。

询问“清除记忆怎么用”只是在问用法，不应执行清除。正文中的 `nomem` 是保留的单次不使用长期记忆选项。普通群发言不会每天自动提炼成你的长期用户画像。

## 角色与回复风格

### 用途

查看和选择角色，添加新的角色，调整回复长短、称呼和语气。

### 使用示例

```text
@机器人 有哪些角色可以选？
@机器人 切换成通用助手
@机器人 联网添加《原神》的安柏并选用
@机器人 以后叫我阿阳，回复简短一点，少用表情
```

### 返回内容与注意事项

机器人会说明当前角色、变更结果或添加失败的原因。联网添加会查找资料；未成功添加时不会假装已经保存。你创建的角色和表达偏好归属于你，不会替其他群成员切换。

角色会影响语气，不改变查询权限、事实和任务发送对象。选择通用助手可关闭虚构角色风格。想看这一次的更多依据，可以直接要求展开，不必修改长期偏好。

## QQ资料与头像

### 用途

查看群成员的 QQ昵称、群名片、头衔和群角色等展示资料，并理解他们当前的 QQ头像。

### 使用示例

```text
@机器人 我的群名片是什么？
@机器人 你的头像是什么？
@机器人 看看昵称的头像，描述一下内容
```

### 返回内容与注意事项

“我的”指提问者，“你的”指机器人自身。头像会实际读取后再描述，角色设定中的外貌不能代替 QQ头像。资料缺失会说明未知；群等级不是王者段位，QQ展示的年龄等信息也不是核验的现实身份。

普通群只能读当前群的成员；管理员私聊可以在授权群里查。普通私聊没有群成员读取权限。本地网页暂时不能读取实时 QQ群成员资料和头像。

## 定时提醒与多次消息

### 用途

延迟发送提醒、按周期发送指定次数，或者定时查询后给你结果。

### 使用示例

```text
@机器人 10分钟后提醒我休息
@机器人 每隔10秒给我发一条消息，发三次
@机器人 每小时查一次指定话题的最新消息，共查两次
@机器人 看看我在这个会话里安排的任务
@机器人 取消刚才的提醒任务
```

### 返回内容与注意事项

先收到创建结果，再在约定时间收到消息。固定文字提醒与需要查询的任务都可安排；支持的最短周期为1秒。未指定首次延迟的周期任务会等待一个周期后开始。

任务发往创建时绑定的当前会话，不能让它偷偷改发给其他人。取消应以成功结果为准。服务停止时不会按时执行；恢复后错过的时间点不会集中补发，异常重启也不能保证通知绝不重复。本地网页任务需要本地服务运行。

## 联网查询

### 用途

查最新网页信息、版本改动或角色资料，并给出可核对的来源。

### 使用示例

```text
@机器人 联网查一下最近王者荣耀版本改动，给我来源
@机器人 搜一下安琪拉近期的调整，整理重点
```

### 返回内容与注意事项

结果通常包含摘要与来源链接。直接表达“联网查”“搜索最新资料”即可，不需要给消息加 &。网络或外部服务失败时会说明，不能把旧知识当成刚查到的消息。

玩家、英雄的昵称和别名也可以询问，但同名或多账号时可能需要你补充对象。

## 图表、创作图片与计算

### 用途

把查到的数据绘成图表，按想法创作图片，或进行需要计算的分析。

### 使用示例

```text
@机器人 把我最近的英雄胜率画成柱状图，标明场次
@机器人 用霓虹夜色主题画最近评分趋势
@机器人 画一张安琪拉在雨夜街头的插画
@机器人 计算这份数据的平均值和分布
```

### 返回内容与注意事项

可以收到柱状图、折线图、热力图等统计图，也可以收到创作图片。图表需要真实数据；数据不足、查询截断或样本很小时会说明，不会为了补齐曲线编造数据。

图片生成可能耗时较长。创作图片不是查询证据。计算环境支持 Python，但不能让生成代码读取服务器私有文件、密钥或任意联网资源。

## 战绩、排行与在线状态

### 个人战绩

使用 `#我的战绩` 查看今天的战报；`#我昨天的战绩` 查看昨天；`#昵称的战绩-8` 查看8天前；`#昵称的战绩7-14` 查看对应天数区间。

返回对局和胜负、评分、段位变化等信息，通常附战绩网页；有可用详情时也可收到最近一局的摘要和图片。数据未收录、战绩不可见或请求过快时可能没有结果。

### 群体排行与巅峰排行

`#排行` 或 `#排名` 查看当日成员战绩榜单。`#巅峰排名` 或 `#巅峰排行` 查看已经收录的历史巅峰排名。历史榜单不能当成此刻的官方实时名次。

### 在线状态

`#在线` 查看已登记的王者玩家和已绑定 Steam玩家的状态；可以展示正在玩的游戏及对局信息。没有绑定或外部数据不可用的成员可能无法展示。

### 按条件查对局

例如 `#查询我和昵称一起玩的排位赛中我评分更高的对局`，按玩家、英雄、日期、模式、结果和表现等条件筛选历史战绩。一局结果可能附详情图，多局通常给列表链接。

在 AI 聊天里也可以直接要求统计和比较已收录战绩。需要官方实时查询或固定格式的业务操作时，优先使用对应的 #命令。

## 英雄表现、梯度与荣耀战力

### 英雄表现

| 想查询什么 | 示例 |
| --- | --- |
| 自己的一个英雄 | #我的安琪拉 |
| 自己的常用英雄 | #我的英雄 |
| 群成员使用同一英雄的表现 | #群u的安琪拉 |
| 群成员整体英雄情况 | #群u的英雄 |
| 本赛季常用英雄 | #我本赛季的英雄 |

`群u` 表示机器人已登记的玩家集合。根据查询类型，返回场次、胜率、MVP、评分、近期表现或榜单。单人单英雄查询使用当前赛季的资料；其他汇总可明确带“本赛季”。

### 今日英雄

`#今日英雄` 获取自己的今日推荐，通常包含英雄、相关资料、推荐理由或图片。它默认针对本人，不要用“昵称的今日英雄”查询他人。每天的推荐会保留当日结果。

### 英雄梯度与战力

`#梯度` 查看英雄梯度长图。`#我的战力` 查看自己的高战力英雄及相关名次；`#战力查询 不知火舞 武侯区` 查看指定英雄在指定地区的荣耀战力榜信息，英雄和地区顺序不限。

地区或英雄无法识别时会要求确认；榜单与梯度可能受数据更新和外部服务影响。荣耀战力数值、梯度评价和你个人的胜率是不同信息。

## 数据分析与指标解释

### 评分、底蕴和时长

| 功能 | 使用示例 | 返回内容 |
| --- | --- | --- |
| 评分趋势 | #我的分析 | 已收录战绩的评分或段位趋势图与说明 |
| 近期底蕴 | #我的底蕴 | 最近7天可用正式对局的底蕴统计 |
| 底蕴排行 | #底蕴排行 | 成员底蕴榜单，可能附图片 |
| 游戏时长 | #我的时长 | 最近两周王者与已绑定 Steam游戏时长 |
| 时长排行 | #时长排行 | 群体游戏时长排行 |
| 实时对局评估 | #我的预言 | 当前对局双方的实力参考；不在对局中会说明 |
| 观战截图 | #我ob | 对局可观战且截图条件满足时返回画面 |

### 群体总览

使用 `#总览b-7` 看近7天的玩家受益受害统计，`#总览e-7` 看评分极值，`#总览k-14` 看拿手英雄，`#总览i-7` 看组队交集。`#总览h` 是近30日英雄受益受害统计；旧文档把 h 当拿手英雄的用法已经改变。

### 怎么理解这些结果

评分反映对局表现；团队贡献指标会结合评分和经济份额衡量相对贡献；底蕴和预言提供历史表现及双方实力的参考。它们不是对未来胜负的保证，也不能仅凭一次比较认定某位玩家的真实水平。

“受益受害”是这份统计口径下的表现差异，不等于已经证明匹配机制针对某个人。比较时留意统计时间、模式、场次以及缺失数据。

## 代表局

### 用途与例子

从某天已经收录的对局里挑选最有代表性的比赛，回看高光、糟糕或极端表现。

```text
#代表局
#昨天代表局
#2026-10-12代表局
```

### 返回内容与注意事项

会收到代表局摘要、战绩长图和点评。省略日期默认今天；当天没有可用对局时会说明。需要使用 # 或 ＃前缀，直接 @ 提问会进入 AI 聊天。代表局是按当前筛选口径挑出的结果，不代表所有模式都参与，也不是每个玩家各选一局。

## 表情包生成

### 用途与例子

按指定模板或你发的参考图生成表情包；可以写文字要求，也可以使用随机模板。

```text
#emoji
#emoji 001 震惊但嘴硬
#emoji template=奶龙 prompt=委屈地说我没事
#emoji 模板=E1_001 提示词=做一个开心贴纸
```

### 返回内容与注意事项

生成成功会返回图片。模板前缀保留前导0；指定模板要能在当前素材中找到。要用自己的参考图片，请在同一条消息中附图片并写 #emoji，图片和命令一起发送。未指定内容时可以结合当前群里本人的最近发言生成，其他群成员的发言不会冒充你的意思。

这项 QQ命令与“理解动态表情”是两种操作。本地网页可以让 AI 创作图片，但没有 QQ的 #emoji 模板命令。

## 戳一戳互动

### 用途与操作

在 QQ群里戳一戳机器人，可以收到文字或表情互动。刚查询过战绩、存在待分析对局时，戳一戳还可能触发双方实力评估；已有观战画面时可以返回截图。

### 返回内容与注意事项

具体结果取决于最近查询和当时状态，存在冷却与维护限制。没有待分析对局时，不会因为一次戳一戳凭空生成战绩。这个操作需要 QQ群事件，本地网页不提供戳一戳。

## 视频订阅与自动推送

### B站 UP订阅

| 操作 | 使用示例 |
| --- | --- |
| 订阅 UP | #订阅B站 罗翔 |
| 查看当前订阅 | #我的订阅 |
| 查订阅 UP的最新视频 | #最新视频 |
| 取消某个订阅 | #取消订阅 罗翔 |
| 取消本人全部订阅 | #取消订阅 |

订阅成功后，机器人会按轮询结果推送新视频。可以订阅多个 UP；重名、无法搜索或找不到账号时，需要补充信息。取消订阅会给出结果。它是 QQ业务命令，AI 聊天没有独立的 UP订阅操作工具。

## 查看完整回复与运行记录

### 怎么用

想看更多依据，直接说“把上面的依据展开”“给我完整结果”。QQ默认通常是简短版，要求完整内容时可以发送详细版。不要因为问题碰巧含有“每个”“前几名”等词就自动切成长报告。

QQ回答可能附图表或运行记录链接。本地网页可以切换查看详细内容与群聊回复，也可以展开执行过程和查看 token用量。

### 会看到什么

详细版保留依据、数据和来源；执行过程可以展示实际工具调用、结果和错误。token用量是接口报告的统计，未知或未完成的用量会说明。只有接口实际返回的思考字段才会展示，不会制造思考过程。

记录可以帮助调试，但查看功能指南不会把聊天日志或原始图片读出来。群聊归档和 AI对话记录是两回事；在本地网页聊天不会被伪装成 QQ群里的原始发言。

## 使用范围

- QQ使用可能需要先由管理员登记你的 QQ号及游戏账号；账号未登记、功能被禁用、休眠或维修时，机器人可能提示无法使用。
- 群内 AI请求只读取当前群的发言和群成员资料，即使管理员在群里提问也是如此。
- 管理员私聊可以查授权群；未指定群时采用设置的默认群。普通私聊不能读取群聊或群成员资料。
- 查询范围不会改变消息的接收位置：在私聊安排的任务仍发到该私聊。
- 本地网页能进行聊天、查资料、数据分析、作图、图片生成、角色和提醒操作；实时 QQ资料、戳一戳及 #业务命令仍是 QQ专属操作。

## 常见问题

### 为什么有时没有回复？

检查是否真正 @ 到机器人、固定命令是否带 #、账号是否已登记，以及是否处于维护、休眠或冷却。明确引用里的 @ 或输入机器人昵称不能代替本次直接 @。

### 为什么数据和我游戏里看到的不一样？

历史战绩和榜单只覆盖已收录且可读取的数据，实时接口也可能延迟或失败。先确认玩家、日期、模式和账号；不要把历史巅峰排行当成实时排名。

### 为什么它不记得群里别人说的话？

连续对话、群聊背景和本人长期偏好用途不同。想了解刚才的讨论可以要求查近期群聊；想保存自己的偏好请明确说“记住”。

### 只是在问功能，会不会直接执行？

询问“怎样定时”“记忆怎么清除”应先得到使用说明。需要执行时明确提出操作，保存、订阅或安排任务以成功确认结果为准。

### 机器人现在用什么模型？

当前本地和远程的 AI文字与图片理解都使用 DeepSeek V4.1 Flash。图片生成是另一项创作服务；不要把它和图片理解混为一谈。
