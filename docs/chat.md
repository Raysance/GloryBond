# AI 聊天运行记录

机器人每次最终回复会将文字、图表和运行记录链接合并为一条消息。多张 Python 图表默认等比合为一张总图，页面仍保留原图入口。

引用一条 QQ 消息后向机器人提问，它会读取被引用消息的文字作为本次分析资料。已撤回或无法读取的消息会标明不可用；图片、语音和视频只识别消息类型，不会自动识别其中内容。引用内容不会自动写入长期记忆。

点击回复末尾的「运行记录」可以查看模型请求轮次、工具输入、只读 SQL、结果预览、绘图代码、错误和耗时。界面采用 DeepSeek Harness 的轨迹查看方式：左侧选择步骤，右侧切换概述、参数、结果、Schema 和计时。顶部三条时间带分别显示输入、模型请求和工具执行。支持搜索、折叠轮次、导出脱敏记录；切换「对话」可阅读答案和放大图表。运行记录展示实际执行过程，包含记忆和群聊工具的调用参数、返回原文、上下文与错误详情；API 密钥等凭据会脱敏，不包含模型私有思维链或系统提示。

记录链接默认保留 7 天，持有链接即可查看；图表原图按现有产物清理周期保留。链接过期后显示过期提示。若发布记录暂时失败，机器人仍会发送已完成的答案，并提示链接不可用。

默认一次聊天最多执行 10 轮工具循环和 16 次工具调用，必要时追加一次最终回答请求；不会把每轮过程分别发到群里。图表源图最多 4 张。
