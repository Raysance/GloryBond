## 一、受益受害指标

$$
I=\frac{G^2}{e^W}
$$

- $G$：平均评分。
- $W$：胜率，使用0至1的小数。
- 数值较小偏“受益”，较大偏“受害”。同样评分下胜率越高，指数越小；同样胜率下评分越高，指数越大。

玩家统计会结合此前90天的个人历史，减小少量近期对局带来的波动。有可用历史时，按历史样本量、近期场次及10至30场的权重限制加权评分与胜率，再代入公式；没有历史时直接使用近期结果。

英雄受益受害按近30天汇总，至少4场才参与，直接使用该英雄的平均评分和胜率。

统计范围为已收录的排位、巅峰和战队赛，排除1v1、2v2、3v3。这项指标描述评分与胜率的关系，不能据此证明匹配机制针对某位玩家。

## 二、拿手英雄指标

$$
\text{拿手程度}=\sqrt{W_h}\times G_h\times\frac{\tanh((N_h-5)/3)+1}{2}
$$

| 参数 | 含义 |
| --- | --- |
| $W_h$ | 统计期内该英雄胜率，取0至1 |
| $G_h$ | 该英雄平均评分 |
| $N_h$ | 该英雄出场次数 |

综合胜率、评分和场次。场次因子以5场为中心，场次增加时逐渐接近1，避免只凭一两场高胜率选出拿手英雄。

使用 `#总览k-14` 可查看近14天各玩家的拿手英雄。

## 三、战局实力评估（底蕴值）

### 1. 个人底蕴

定义：

$$
\sigma(x)=\frac{1}{1+e^{-x}},\qquad E=(S-25)+\frac{P-1200}{15}
$$

$E\leq0$ 时取1。当前个人底蕴为：

$$
L=E^{0.3}\times\sigma(M)^4\times(T/10000)^{0.85}\times\frac{8+R}{2}\times\sigma(N/10)^{1.3}\times\sigma((H+B)/20000)^2\times\max(W/0.5,1)^2
$$

| 参数 | 含义 |
| --- | --- |
| $S$ | 累计段位星级，王者0星对应50 |
| $P$ | 巅峰分 |
| $M$ | 总 MVP 场次 ÷ 总场次 |
| $T$ | 总战斗力 |
| $R$ | 近期可用正式对局的平均评分 |
| $N$ | 本局英雄历史胜场与负场之和 |
| $H$ | 本局英雄战力 |
| $B$ | 返回列表中战力不低于 $H$ 的前3个英雄的平均战力；没有时取 $H$ |
| $W$ | 近期正式对局胜率 |

近期正式对局至少10场时使用实际胜率，不足时使用55%的预设值；平均评分有可用正式对局即可更新。胜率低于50%时，胜率因子保持1。

未授权玩家不计入团队底蕴。资料读取失败或字段缺失会影响评估，部分字段使用预设值。

### 2. 双方实力

$$
\text{实力天平倾斜度}=\sum\text{我方有效玩家底蕴}-\sum\text{对方有效玩家底蕴}
$$

正值表示我方底蕴较高，负值表示对方较高。底蕴是综合参考，不保证对局胜负。

### 3. 近期统计与排行

- `#我的底蕴` 默认近7天，只统计已完成评估且能定位本人记录的正式对局。
- 待评估对局不按0补入，统计胜率也仅对应已评估样本。
- 我方、对方、差值和个人底蕴，分别对有效对局取平均。
- 底蕴排行按每局“双方团队底蕴之和 ÷ 2”的跨局平均值降序排列。
- 近期统计中的个人相对底蕴，以每局有效玩家平均值为100%；单局图卡以最高玩家为100%，两者基准不同。

## 四、团队贡献系数

$$
C=\frac{5\times\text{个人评分}}{\text{本方总评分}}\times\left(\frac{5\times\text{个人经济}}{\text{本方总经济}}\right)^{-0.5}
$$

结合评分份额与经济占用。同样评分份额下，经济占用越低，系数越高。评分和经济均占本方20%时，系数为1；它不等同于官方 MVP 或伤害占比。

最终装备含学识宝石、近卫或极影时，括号内的经济项先除以0.9，再计算负0.5次方。

无法读取本人、阵营或有效评分与经济时，没有有效系数。历史平均只纳入正式对局中详情完整、可计算的样本。

## 五、代表局筛选指标

### 1. 候选范围

- 从指定日期已收录的排位、巅峰、战队、匹配及王者峡谷对局中选择，排除1v1、2v2、3v3。
- 结果为胜利或失败，评分0至20，时长5至120分钟。
- 同一局被多人记录时，保留代表性最高的视角。

### 2. 三类指数

每个分项将实际值换算为0至1的比例，再乘权重；各类累计后最高100分。

上涨型比例为“(当前值−起算值) ÷ (满分值−起算值)”，下降型比例为“(起算值−当前值) ÷ (起算值−满分值)”，结果限制在0至1之间。

| 高光封神 | 起算 → 满分 | 权重 |
| --- | --- | --- |
| 高分 | 8 → 16分 | 25 |
| 队内高分 | 相对队友均分与最高分 | 15 |
| KDA | 3 → 8 | 15 |
| 输出占比 | 25% → 40% | 10 |
| 承伤占比 | 25% → 40% | 8 |
| 参团率 | 60% → 85% | 7 |
| MVP | 命中即得分 | 7 |
| 多杀 | 三杀37.5%、四杀62.5%、五杀及以上100% | 8 |
| 超神 | 命中即得分 | 3 |
| 一血 | 命中即得分 | 2 |

| 峡谷渡劫 | 起算 → 满分 | 权重 |
| --- | --- | --- |
| 低分 | 8 → 3分 | 35.55 |
| 队内低分 | 相对队友均分与最低分 | 23.7 |
| 低 KDA | 2.5 → 0 | 23.7 |
| 低贡献效率 | 0.8 → 0.4 | 23.7 |
| 死亡数 | 6 → 12次 | 11.85 |

其中，贡献效率 = 输出占比与承伤占比的较大值 ÷ 经济占比，与上节团队贡献系数不同。

| 离谱剧本 | 起算 → 满分 | 权重 |
| --- | --- | --- |
| 速胜速败 | 10 → 5分钟 | 102 |
| 超长对局 | 24 → 40分钟 | 102 |
| 评分逆风获胜 | 敌方总评分领先2 → 12分 | 102 |
| 评分领先却败 | 我方总评分领先2 → 12分 | 102 |

缺少详情时，只计算已有数据支持的分项。

### 3. 代表局排序

每局取三类指数中的最高值，按该值选出当天代表局。同分时依次比较命中标签数、详情完整性、评分偏离8分的程度、时长及对局时间。

没有符合条件的候选时会说明；每位玩家并非各选一局。普通查询依次展示摘要、战绩图和点评。

## 六、其他统计范围

| 统计 | 范围 |
| --- | --- |
| 正式平均评分 | 排位、巅峰和战队赛，排除1v1、2v2、3v3，取算术平均 |
| 常用英雄汇总 | 默认近30天、每榜前3，胜率和评分榜默认至少2场；群体查询门槛可不同 |
| 王者游戏时长 | 近两周已收录对局持续时间，换算为小时 |
| Steam 游戏时长 | 已绑定账号的近两周游戏时长，换算为小时 |

游戏总时长直接相加，不排除多设备同时运行的重叠时间。历史记录缺失或战绩不可见时，统计可能不完整。
