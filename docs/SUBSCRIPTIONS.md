# 订阅说明

## B站 UP 视频

| 操作 | 命令 |
| --- | --- |
| 订阅 UP | `#订阅B站 罗翔` |
| 查看本人订阅 | `#我的订阅` |
| 查看最新视频 | `#最新视频` |
| 取消指定 UP | `#取消订阅 罗翔` |
| 仅有一个订阅时取消 | `#取消订阅` |

- 支持订阅多个 UP，按名称搜索匹配；遇到同名时需补充信息。
- 按账号跟踪，UP 改名后继续有效。
- 订阅成功时返回最新视频，之后默认每5分钟检查新视频。
- 推送包含视频标题、UP、发布时间、封面和链接。
- `#最新视频` 查询本人所有订阅 UP 的最新公开视频。
- 多个订阅时，取消需指定 UP 名称或账号 ID，空命令会提示选择。

视频链接在电脑端打开网页，手机端会尝试唤起 Bilibili App。

## X 账号

| 操作 | 命令 |
| --- | --- |
| 按用户名订阅 | `#订阅X @XDevelopers` |
| 按主页链接订阅 | `#订阅X https://x.com/XDevelopers` |
| 查看本人订阅 | `#我的X订阅` |
| 查看最新内容 | `#X最新内容` |
| 取消指定账号 | `#取消X订阅 @XDevelopers` |

### 账号与推送

- 支持多个账号，用户名不区分大小写；也支持 twitter.com 主页链接。
- 使用账号用户名或主页链接，不支持按显示昵称搜索。
- 默认只推原创公开帖，不推转帖和账号自己的回复。
- 首次订阅返回最新帖预览，自动推送不补旧帖。
- 默认每5分钟检查，新帖发布至少5分钟后推送，等待回复积累。
- 同一账号被多人订阅时，只推送一次。
- 未指定取消对象时，只有本人恰好订阅一个账号才直接取消。

### 消息内容

```text
作者名 · 发帖时间（多久前）
中文内容预览
[图卡，长内容可有多张]
原帖链接
```

时间采用原帖发布时间，按北京时间显示到秒。中文预览默认最多280字符，超出后提示“全文见图”。

图卡包含完整正文、可读取配图、热门回复和英文内容的中文译文。中文译文优先展示，英文原文保留；长内容分页，不按预览长度截断。视频只提供预览，需打开原帖观看。

### 热门回复与翻译

热门回复从可见公开回复中采样，默认最多读取100条，按点赞数选取5条，也可能包含楼中楼。卡片会标注采样范围，不代表 X 全量热门排名。

无回复、读取失败或翻译失败时会明确标注。翻译失败保留原文；回复与点赞为生成时的快照，不持续更新已发送图卡。

### 网页读取维护

读取使用 `.env` 中的 `HOK_X_AUTH_TOKEN`、`HOK_X_CT0` 与现有 `Proxy.clash_url`，不调用开发者付费 API。新版 x-web 首页通过内联入口加载模块，程序静态读取当前公开脚本，发现 transaction 签名索引、Relay 查询 ID 与提供变量；不会执行网页 JavaScript。公开脚本按内容版本 URL 在进程内限量缓存，登录页面、Cookie 和帖子响应不进入该缓存。旧网页加载方式仍兼容。

新版原创查询为 `UserOriginalsTimeline`，含回复查询为 `UserTweets`，详情查询为 `TweetDetail`。`XSubscriptions.web_query_ids` 在新版中按这些实际操作名覆盖查询 ID；旧网页仍使用原操作名，`web_features` 仅用于旧网页协议。接口 ID 覆盖不能替代返回结构适配。时间线按发布时间排序读取，支持新版正文、长文、媒体、回复和点赞字段。

订阅记录继续绑定稳定账号 ID，读取前通过受限的 X 主页跳转获取当前用户名，账号改名无需重新订阅。引用帖、置顶帖和广告不作为独立新帖；失败时不推进游标，避免漏推。

错误提示区分网络/代理连接失败、读取超时、会话不可用及网页适配变化。首页 HTTP 200 只说明页面可达，不能证明帖子接口可用。适配回归应同时检查账号、原创/含回复时间线、详情及分页，不能只检查首页。会话错误时才核对登录状态与 Cookie；脚本映射、查询或结构错误需更新适配代码。

## 接收范围与常见问题

**Q：推送发到哪里？**

A：B站与 X 自动通知发往已接入的推送群，订阅记录按本人保存。主动查询结果回复到当前会话。

**Q：重启后需要重新订阅吗？**

A：不需要，成功保存的订阅会保留。

**Q：为什么暂时没有新消息？**

A：可能还未发布新内容、未到检查时间，或外部服务暂时不可用。X 还需等待发帖后的回复积累时间；会话失效时需管理员恢复服务。

**Q：可以直接 @机器人 要求订阅吗？**

A：请使用上面的 `#` 命令。聊天可以询问用法，订阅成功以命令回复为准。

**Q：两类订阅会互相覆盖吗？**

A：不会。B站与 X 独立管理，`#我的订阅` 和 `#最新视频` 仍用于 B站。
