# 账号登录态

登录管理员控制台，进入「账号登录态」，点击对应账号的「检查状态」。页面分别显示王者营地、王者官方客户端和 NapCat QQ 的状态。检查结果保留5分钟；无法连接时显示「待确认」，不代表已掉线。

失效或无法确认时，点击「扫码重新登录」，使用原配置的 QQ 账号扫码并确认，页面会显示完成结果。营地与官方客户端需要分别授权，成功后机器人与网页的后续查询自动使用新凭据。NapCat 使用机器人 QQ 账号，由 NapCat 自行保存登录态。

请勿转发二维码。扫码会话最长保留4分钟；QQ 可提前使二维码失效，页面会提示重新生成。发布或服务重启后也需重新生成。遇到冷却提示请等待指定时间；扫错账号不会覆盖原凭据。配置和安装说明见 NBot 的 `deployment/README.md`。
