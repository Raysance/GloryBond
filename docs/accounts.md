# 账号登录态

登录管理员控制台，进入「账号登录态」，点击对应账号的「检查状态」。页面分别显示王者营地、王者官方客户端和 NapCat QQ 的状态。检查结果保留5分钟；无法连接时显示「待确认」，不代表已掉线。

点击「扫码登录 / 切换账号」，使用希望切换到的 QQ 账号扫码并确认，允许与原账号不同。三种服务分别授权，只更新本次授权的服务。成功验证后同步更新身份、凭据和角色/区服，后续查询自动使用新登录态；白名单、管理员和已绑定玩家保持不变。

营地自动采用唯一角色或服务端标记的唯一主角色；有多个角色且无法确定主角色时，页面会显示选择框。新账号没有角色时清空原角色。NapCat 的「同步 / 扫码登录」在在线时同步实际登录 QQ，离线时展示扫码二维码，成功后更新机器人 QQ 及重启登录账号，并保留原 Bot 的 OneBot 连接。

请勿转发二维码。扫码会话最长保留4分钟；QQ 可提前使二维码失效，页面会提示重新生成。发布或服务重启后也需重新生成。遇到冷却提示请等待指定时间；只有验证成功后才替换原凭据；管理员扫码确认即表示选择该账号。配置和安装说明见 NBot 的 `deployment/README.md`。
