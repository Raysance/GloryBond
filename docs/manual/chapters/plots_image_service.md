# 创作图片的服务、模型与返回方式

创作图片使用APIMart的图片生成服务，公开接口为 https://api.apimart.ai/v1/images/generations 。当前配置初始模型为gpt-image-2，实际模型可由运行设置调整；这是生图服务，与负责文字聊天的DeepSeek及负责图片转写的豆包不同。

AI聊天的生成工具每次请求1张图，默认比例1:1、分辨率1K，可提出画面内容和比例要求。服务先返回任务，再等待生成完成并读取图片；失败、取消或超时不会被当作生成成功，通常耗时比文字回复长。

生图任务默认等待生成600秒，并为提交、下载与发送预留外层时间。等待期间每隔2分钟提示一次仍在处理，完成或失败后停止提示；进度提示不会重新提交请求。QQ和本地聊天的整轮默认预算为1200秒，定时任务沿用相同预算及更长租约。超时只能说明尚未确认结果，不能据此认定服务端已取消，也不会自动重复提交。

通用AI生图工具可按需通过 reference_image 传入参考图：支持本轮附件编号、公开图片 URL 或授权本地路径。宿主校验并处理图片后传给原生图 API，不会把图片像素放进主对话，也不要求先调用识图。QQ 的 #emoji 参考图与模板命令仍沿用原有流程。

图片生成需要服务可用且凭据配置正确，不能在回答中展示密钥。统计绘图使用查到的数据计算并渲染，不通过这个生图API伪造数据图；生成的画面也不是事实查询证据。
