# 图片、音视频、引用和动态表情

### 用途

描述图片内容、理解截图，或针对明确引用的消息继续讨论。动态表情会取若干画面来理解，不能保证看到了整个动画。

### 使用示例

```text
发送一张图片，再 @机器人：这张图里有什么？
引用别人发的图片，再 @机器人：这个表情是什么意思？
引用一条发言，再 @机器人：这句话是在回应什么？
@机器人 刚才群里发的那张截图上写了什么？
（回复群文件）@机器人 总结这份 PDF，注明文件名和依据。
```

### 返回内容与注意事项

要看本群近期图片，可以直接描述发图的人或问“刚才那张截图”。机器人按需查看 QQ 最近返回的 50 条群消息，默认取一张，可指定多张。只看提问前的本群图片，原图和发言者按消息对应。已过期、撤回或超出窗口的图片可能无法取回。

QQ 支持读取当前消息和明确回复的文件，本地网页可选择或拖入附件。支持 PDF、DOC/DOCX、PPT/PPTX、XLS/XLSX、TXT、MD、CSV、TSV 和 JSON，每轮最多 4 份，每份最多 16 MiB。PDF、Word、PPT 用 DeepSeek 图文解析，文档有效期 24 小时，可在同一对话追问。成功解析按页收费，每次引用按模型实际输入量计费。文本和表格上传免费。[DeepSeek 文件解析说明](https://api-docs.deepseek.com/zh-cn/guides/document_parsing/)

机器人会说明实际读到的内容。没有可读取的媒体地址、图片损坏或范围不允许时，会说明未读取，不会仅凭表情编号猜图。当前消息和引用图片共用单轮预算；默认最多4张、单张4 MiB、合计8 MiB。

动态图片默认抽取最多4帧。引用只展开本次明确引用的那条消息，不连续追溯整条引用链；其中的命令不会执行。

QQ 当前消息或明确引用的原生视频、语音可通过 `read_media` 按需读取，每轮最多附加或引用4份，单份最多50 MB、10分钟。默认每10秒抽一帧，完整第一音轨转为单声道后按115秒分段，最多6段同时调用 DeepSeek ASR，再把全部转写与带时间标记的采样帧交给 DeepSeek Flash 分析。超出时长直接提示，不静默截断。未采样的动作细节、ASR没有保留的音乐、音效和语气无法确认。

可以回复视频后问 `@机器人 总结主要观点，指出对应时间段`。工具也支持公开音视频文件直链和管理员授权目录内的本地文件；播放器网页链接需先取得实际媒体来源。本地网页共用直链/路径工具，附件上传界面仍仅接受原有图片和文档。QQ原生语音依赖平台的WAV转换，平台返回本地文件时须位于管理员配置的 `qq_media_roots` 内。

工具不会在收到视频时自动下载或调用模型。视频、采样帧、每段转写及同一问题的答案使用私有缓存，重复读取复用已有结果；新问题仍可能产生新的分析 token。语音按识别秒数计费，Flash 按图片和文字的输入/输出 token 计费，返回实际用量，公开单价见 [DeepSeek 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

本地网页可以选择、粘贴或拖入图片。功能指南里的演示图片只供人查看，机器人查手册时忽略它们。

QQ 与本地网页的识图可以独立使用豆包 Seed 2.1 Lite，图片追问仍保留原有上下文和工具能力，纯文字聊天沿用原模型。管理员须先配置并开通对应模型；识图服务未开通或调用失败时会说明失败，不能把未成功读取的内容当成已识别。申请与配置见[豆包识图接入](../../../src/glorybond/agent/README.md#豆包识图接入)。
