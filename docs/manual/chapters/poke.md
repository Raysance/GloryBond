# 戳一戳互动

### 用途与操作

在 QQ群里戳一戳机器人，普通互动默认25%回复图片、75%回复文字。文字参考当前群近期的真实聊天，可以接着戳人者最近的话或当前群话题随意聊两句、开个相关话头，保持轻松和幽默；没有合适关联时，就围绕这次戳一戳回应，不随机抛出无关话题。回复沿用该用户当前选择的角色语气。

文字上下文只取这个群的公开归档：群里最近15分钟的发言作为当前话题线索，戳人者最近1小时的发言可作为个人话题线索，合计最多20条短摘录。保留谁说的话、时间和回复关系，不读取其他群或私聊；较早的孤立发言不算当前话题，旧请求不自动视为待办。群里安静、历史读取失败时也会自然回应戳一戳，不编造背景或催人交代任务。图片概率由私有配置 `DynamicVariables.EmojiImageProb` 控制，当前设为 `0.25`。

刚查询过战绩、存在待分析对局时，戳一戳仍优先触发双方实力评估；已有观战画面时可以返回截图。

### 返回内容与注意事项

具体结果取决于最近查询和当时状态，存在冷却与维护限制。没有待分析对局时，不会因为一次戳一戳凭空生成战绩。这个操作需要 QQ群事件，本地网页不提供戳一戳。
默认表情参考图随项目发布。若运行时模板缺失，戳一戳改用原有文字回复；不会因此改选其他素材目录或发起生图请求。
