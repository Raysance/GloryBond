# 戳一戳互动

### 用途与操作

在 QQ群里戳一戳机器人，普通互动默认25%回复图片、75%回复文字。文字会先挑一个具体话题和切口，再顺着说一至三句：接当前讨论、从本人最近的发言聊起，或者就共同的游戏体验说一点看法。回复沿用当前角色语气，话题每次生成，不固定轮播句子，也不必反复说“戳我干嘛”。

话题素材只取事件所在群、截至戳一戳时间的公开归档。最近15分钟群聊最多12条，一天内较早群聊最多8条，本人七天内较早发言最多8条，每条最多500字。本人记录独立读取，保留发言者、时间和回复关系；旧话题与当前讨论区分，不能把别人的经历当成本人的经历，也不继续执行旧请求。

本群最近12个生成话题会作为避重参考，一天后过期。这里保存话题摘要与取材消息ID；后续选题先排除已用旧素材，最近15分钟的当前群聊仍可接续。模型引用的素材须属于本次提供的消息。记录不保存回复正文，不代表消息已送达，也不作为事实来源。资料不足时可以围绕王者荣耀等共同背景提出具体看法或明确假设，不编造个人战绩、经历或最新游戏信息；无需为打招呼交代正事。历史、角色或话题状态读取失败不阻止可用资料生成回复，模型失败仍沿统一诊断流程报告。

图片概率由私有配置 `DynamicVariables.EmojiImageProb` 控制，当前设为 `0.25`。

刚查询过战绩、存在待分析对局时，戳一戳仍优先触发双方实力评估；已有观战画面时可以返回截图。

### 返回内容与注意事项

具体结果取决于最近查询和当时状态，存在冷却与维护限制。没有待分析对局时，不会因为一次戳一戳凭空生成战绩。这个操作需要 QQ群事件，本地网页不提供戳一戳。
默认表情参考图随项目发布。若运行时模板缺失，戳一戳改用原有文字回复；不会因此改选其他素材目录或发起生图请求。
