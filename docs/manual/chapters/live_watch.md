# 当前对局观战截图

发送 `#观战昵称` 或 `#观战配置简称` 查询已登记玩家；`#观战我` 和 `#我的观战` 使用发送者绑定的游戏账号。

机器人先回复正在获取。同一群聊或私聊首次观战某局时，先发送双方阵容图片，再返回观战截图。阵容使用原有底蕴／预言模板，只填入此次观战响应直接提供的昵称、英雄、头像、英雄战力和英雄胜负场次之和；缺失数据、底蕴、总 MVP 率和预测结论留空，不额外查询每位玩家的资料。字体、布局、头像裁剪沿用原模板，英雄头像优先使用原有本地资源，其他头像同时加载并缓存。红绿底色按现有英雄战力、场次和胜率作相对比较，缺项不参与；这不是完整底蕴分。

等待画面分配最多60秒，随后读取视频的超时为10秒。首次返回可能是加载或加速追赶画面；成功截图后保持同一目标的直播、心跳和后台读取，只保留最新一帧。再次观战等待本次请求之后的新帧，不重新申请同一直播；不自动持续发图。对局结束、读取失败、切换目标、登录态更新或服务退出时清理连接。

阵容图片按机器人、当前会话和对局去重一天。入队不等于送达：明确发送失败后，下一次手动观战可以重新发阵容；发送结果未知时不重复发送。

目标未开局、当前对局不允许观战、等待超时或读取失败时会给出提示。失败不会自动重新登录或重复申请。每个 Bot 进程只保留一路直播，多人看同一目标可复用；切换到另一位玩家会关闭旧直播，切回时重新申请。正在获取另一张截图时会提示稍后再试，避免同时发起多个观战。直播画面可能有服务端延迟，不保证与玩家手机同一时刻。

该命令沿用前缀命令的权限和玩家登记规则。未知昵称或未绑定的“我”不会触发查询，也不接受任意直播地址。返回的是画面图片，不包含账号凭据或带签名的播放链接。旧 `#我ob` 入口保留；`#我的预言` 继续用于当前对局双方实力分析。
