# 底蕴统计的样本与排行口径

#我的底蕴默认查询最近7天。正式对局口径包含排位、巅峰和战队赛，排除1v1/2v2/3v3；不是所有娱乐模式都参加。

只统计已经保存底蕴评估、且能够定位本人记录的对局。未评估的正式对局会单独提示待评估数量，不会用0补进有效样本。胜率也按这一批已评估样本计算，可能与全部战绩胜率不同。

单局我方/对方底蕴是该侧有效授权玩家的个人底蕴之和。近期统计的我方、对方、差值和个人底蕴分别对有效对局取算术平均。

“个人底蕴/队友对手底蕴”先在每局计算本人底蕴÷该局底蕴大于0的所有玩家平均底蕴×100%，再对各局取平均。这个100%基准是有效玩家平均值，不能与单局图卡以最高玩家为100%的显示混用。

底蕴排行按每局(己方团队底蕴+对方团队底蕴)/2的跨局平均值降序排列；不是按个人单人底蕴排序。榜内同时展示个人及双方指标，必须看清列名和有效场次。

AI 聊天可以按自定义玩家、日期或精确时间段查询底蕴。比如“比较我和某成员11月1日至10日的个人底蕴”，或“看我昨天18点到22点遇到的对手，统计他们的巅峰分和近期胜率”。QQ 与本地 Web 均使用独立的 `analyze_power_database` 工具，发现类别为 `power_data`。

查询直接读取已保存的整局 power 业务 JSON，包括双方指标、全部参赛玩家的英雄战力、历史胜率和评分、段位、巅峰分、MVP率及近期表现，以及已有的英雄对位数据和分析。未登记的同局玩家也可统计；内部账号信息、头像链接和原始错误正文不提供给模型。某局未评估时不会现场补算。

日期和时间段按实际开局时间筛选，起点包含、终点不包含；查某天时使用当天零点到次日零点。评估时间是另一种时间，不能代替开局时间。缺少开局时间的记录不计入指定时间区间；未指定时间时可以读取并注明未知。个人及队友数据是评估时资料，部分字段可能来自旧评估算法的预设值，不代表当前状态或该局表现。

AI 可自定义统计和排序，不受旧7天统计格式限制；固定命令 `#我的底蕴` 和 `#底蕴排行` 保持原有用法。模型工具目录含字段、玩家筛选、同局关联和完整 SQL 示例。

自定义统计区分个人底蕴、对手团队底蕴和双方平均底蕴。双方平均仅在两侧数值有效时计算；人机局、缺失值与有效均值样本分别计数。活动间隔来自完整已收录战绩（包括未做底蕴评估及其他模式的对局），仅表示归档中前后对局的间隔。评估表中的行序只表示第几个已评估样本，不能当作实际第几局；连续过程应先在完整战绩上定义，再关联评估。

按项目约定，对面完整5人都未授权营地，且整队底蕴显示unknown时，标记为人机局。数据中使用可空的 `rival_side_is_bot` 表示目标玩家是否遇到人机队；人数或授权信息不足为未知。仅仅没有登记在项目名单、昵称为unknown或接口请求失败，都不满足这条规则。此标记来自项目分析口径，原始数据没有官方人机标签。
