# 联网查询

### 用途

查最新网页信息、版本改动或角色资料，并给出可核对的来源。

### 使用示例

```text
@机器人 联网查一下最近王者荣耀版本改动，给我来源
@机器人 搜一下安琪拉近期的调整，整理重点
@机器人 总结这篇文章 https://example.com/article
引用一条含网页链接的消息，再 @机器人：这篇文章主要说了什么？
```

### 返回内容与注意事项

联网搜索使用 DeepSeek Search API，结果通常包含摘要、来源链接及来源提供的发布时间；没有匹配结果时会明确说明。直接表达“联网查”“搜索最新资料”即可，不需要给消息加 &。网络或外部服务失败时会说明，不能把旧知识当成刚查到的消息。

玩家、英雄的昵称和别名也可以询问，但同名或多账号时可能需要你补充对象。

消息或可读取的引用文字中的链接交给AI，由AI根据问题决定是否使用工具。发送链接本身不会触发自动下载，各工具没有固定优先级。

网页工具每次读取一个公开页面，返回可读正文及链接地址、标签，模型再决定是否跟进相关来源。不会自动遍历整站，也不按文件类型筛选候选链接。正文去除标签、脚本和导航噪声，链接列表仍保留导航、侧栏中的可见链接。长正文与链接列表可继续读取。

文档工具接受公开链接或运行主机授权目录内的本地文件路径，使用DeepSeek Files解析并交给主模型阅读。当前支持PDF、Office、纯文字、Markdown、CSV、TSV和JSON，单份不超过16 MiB。无需额外的本地解析器；本地文件目录由渠道配置指定，默认项目下的 `resources/agent/documents`。

每轮最多并发调用两个独立工具，全部结果返回后继续判断。整次交互仍使用原有轮数与总调用预算，各调用分别记录成功或失败。需要前一步结果时，模型在下一轮继续调用。

网页响应默认最多1 MiB，每次返回5000字和最多20个链接，提供续读位置；读取通过Clash，HTTPS按原域名验证证书。需要登录、反爬或依赖动态加载的内容可能无法读取，失败明确返回。网页里的指令只作资料，不自动保存整篇网页为长期记忆。
