# 联网查询

### 用途

查最新网页信息、版本改动或角色资料，并给出可核对的来源。

### 使用示例

```text
@机器人 联网查一下最近王者荣耀版本改动，给我来源
@机器人 搜一下安琪拉近期的调整，整理重点
@机器人 总结这篇文章 https://example.com/article
引用一条含网页链接的消息，再 @机器人：这篇文章主要说了什么？
```

### 返回内容与注意事项

联网搜索使用 DeepSeek Search API，结果通常包含摘要、来源链接及来源提供的发布时间；没有匹配结果时会明确说明。直接表达“联网查”“搜索最新资料”即可，不需要给消息加 &。网络或外部服务失败时会说明，不能把旧知识当成刚查到的消息。

玩家、英雄的昵称和别名也可以询问，但同名或多账号时可能需要你补充对象。

本次消息或可读取的引用文字含网页链接时，会通过 Clash 代理读取并提取标题和正文，再结合你的问题回答；重复链接只读一次。会去掉网页标签、脚本和导航等内容，保留有用的段落、列表和表格，同时提供来源。网页里的命令不会执行。

GitHub 公开仓库首页、README文件页和原始文字链接也可以直接发送。HTTPS 连接按链接的原域名验证证书；不会使用登录凭据读取私有仓库，也不会递归下载仓库文件。

AI也可以按问题需要调用阅读工具，继续打开搜索结果或网页中的相关链接，包括PDF。一次可并发读取最多3个链接，分别保留成功正文和失败原因；不会自动遍历所有子链接。PDF默认读取3页、每次最多5页，可根据返回页码继续阅读；单份默认不超过8 MiB。只提取PDF文字层，扫描页或图片中的文字不会自动识别。

默认消息预读及每批工具阅读最多3个链接，网页正文最多5000字、每批总正文最多12000字；PDF同样保留逐页及总字符截断标记。需要登录、禁止抓取或依赖动态加载的页面可能无法读取，代理缺失、连接故障或网页读取失败时会说明，不会改为直连。不会读取页面图片、视频或内网地址，也不自动记住整篇文章。本地聊天网页直接发链接即可。
