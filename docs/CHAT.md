# 智能对话说明

[← 返回使用指南](../README.md#四智能对话)

## 聊天与追问

直接 @机器人 后提问即可，固定功能继续使用对应的 `#` 命令。

```text
@机器人 分析一下我最近7天的排位表现
@机器人 主要问题在哪？
@机器人 内容多的话分几条发，讲清楚就行
```

- 支持连续追问；群聊回复会 @ 本次提问者。
- 通常发送简短的群聊版，需要完整结果时可要求展开。
- 回答较长时，可以分几条发送；已发内容会保留，便于继续追问。

## 图片与引用

- 将图片和问题放在同一条消息中发送，或引用图片后 @机器人。
- 支持截图和可读取的动态表情；动态图片默认最多取4帧理解。
- 默认每次最多4张图片，单张4 MiB、合计8 MiB；直接图片与引用图片共用额度。
- 只展开本次明确引用的消息，不连续追溯引用链。引用中的命令不会执行。
- 无法读取的图片会说明；目前不支持通用视频内容识别。

## 群聊背景

```text
@机器人 刚才大家在聊什么？
@机器人 查一下昨天关于组排的讨论
```

可以查看近期窗口，也可以按话题、时间或发言者查相关记录。近期窗口默认15分钟、20条，上限60分钟、50条；查询结果可能为摘录。

群内只查当前群。普通私聊不能读取群聊；管理员私聊可查已授权群，未指定时使用默认群。

## 记忆与角色

| 操作 | 示例 |
| --- | --- |
| 保存偏好 | `@机器人 记住我喜欢玩中路` |
| 查看记忆 | `@机器人 你记得我的哪些偏好？` |
| 纠正理解 | `@机器人 我一直主玩中路，你之前理解错了` |
| 更新偏好 | `@机器人 我现在主玩小乔，不玩安琪拉了` |
| 删除一条 | `@机器人 忘记我的英雄偏好` |
| 清除记忆 | `#清除记忆` |
| 查看角色 | `@机器人 有哪些角色可以选？` |
| 切换角色 | `@机器人 切换成通用助手` |
| 添加角色 | `@机器人 联网添加《原神》的安柏并选用` |
| 调整语气 | `@机器人 以后简短回答，少用表情` |

记忆保存本人的稳定偏好和明确说明，纠正后更新对应内容，其他偏好保留。临时状态、玩笑和引用他人的话不会自动保存为本人事实。

正文加入 `nomem` 可让本次对话不使用长期记忆。`#清除记忆` 清除本人长期事实和当前对话上下文，不删除群聊原始记录、运行记录、角色偏好或其他会话。

角色和语气按个人保存，不替其他成员切换，也不改变查询权限。

## 联网与网页阅读

```text
@机器人 联网查一下最近的版本改动，给我来源
@机器人 总结这篇文章 https://example.com/article
```

直接提出搜索要求即可，无需 `&`。正文或引用中的网页链接可用于本轮阅读；默认最多3页，每页5000字，总计12000字，超出时会提示。

网页阅读只提取文字，不读取页面内的图片、视频或 PDF。需要登录或无法取得正文时会说明。

## 图表与图片

- **统计图表**：根据实际数据生成柱状图、折线图、散点图、热力图和环形图，可要求标明场次、时间和单位。
- **创作图片**：根据文字描述生成图片，可以提出比例和画面要求；通常比文字回答耗时更长。
- **参考图表情包**：将图片与 `#emoji` 放在同一条消息中发送。普通聊天生图不会自动使用聊天图片作参考。

## 提醒与后续消息

```text
@机器人 10分钟后提醒我休息
@机器人 每隔10秒发一条“喝水”，发三次
@机器人 每小时查询一次指定话题，共查两次
@机器人 看看我在这个会话里安排的任务
@机器人 取消刚才的提醒
```

创建成功后，在约定时间收到消息。最短周期为1秒，未指定首次延迟时等待一个周期后开始。消息发往创建时的会话。

服务停止期间无法按时执行，恢复后不集中补发错过的消息。取消以成功回复为准。

## QQ 资料与头像

可以查询当前群成员的昵称、群名片、头衔和群角色，也可以要求描述真实头像。

管理员可发送或引用图片后说“把这张图设为你的QQ头像”，也可要求“生成一张猫咪图片并设为你的QQ头像”。多张图片时需指定第几张。

普通用户不能更换机器人头像；网页聊天不提供实时 QQ 成员资料和头像操作。

## 回复记录

回答可附运行记录链接，查看详细回复、群聊版和实际查询过程。链接有有效期，记录可能包含对话内容，分享前请确认。

本地聊天网页可直接输入上述问题，无需 @；支持选择、粘贴和拖入图片，也能查看回复版本和执行过程。QQ 固定命令、戳一戳和订阅命令需在 QQ 使用。
