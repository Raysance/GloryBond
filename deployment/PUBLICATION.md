# 私有与公开仓库

`Raysance-Studio/HOK_QQBot` 是完整私有源仓库。源码、`.env`、`config.yaml`、部署配置及相关文档保留真实内容，公开发布工具不会反向修改或清空私有文件。三个独立SDK以固定Git submodule及源码链接组成完整项目。

凭据不集中放在 `config.yaml`。API key、token、密码、数据库连接串和账号会话由唯一 `.env` 保存；端点、代理、非密钥策略、玩家昵称、QQ/游戏账号映射等配置由唯一 `config.yaml` 保存。后者仍含个人身份和部署信息，因此也不直接发布到公开仓库。数据库连接缺少配置时明确报错，不使用代码内置账号或连接串。

`Raysance/GloryBond` 是从当前私有版本生成的公开快照，采用相同的统一目录结构。公开内容包括可公开源码、README、完整功能手册、网页说明及已有演示资源；配置、凭据、身份映射、生产地址、运行数据、私有部署文件及新增私有图片均排除。结构化战绩样例仅保留字段结构，值清空；源码及说明中的已配置身份信息匿名化。私有SDK只发布固定版本引用，不复制实现。

同步及检查工具位于公开仓库的 `tools/sync_public_snapshot.py` 和 `tools/verify_public_snapshot.py`。它们只读本仓库，公开前检查实际Git暂存区中的文件路径、已知凭据、身份及部署信息，以及README、功能手册和依赖引用是否齐全。审核输出只报告文件位置和计数，不回显凭据值。公开仓库的脱敏规则不适用于私有源仓库；运行日志和公开分享页仍按原有协议脱敏。
