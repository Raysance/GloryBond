# 战绩网页

查询战绩时，已绑定客户端账号的玩家会同时读取营地和客户端战绩，去重后汇总。营地未收录的客户端对局也会保存详情，可以从单人战绩、周期战绩、历史查询和战报总览中点击查看。

详情沿用现有页面，展示实际取得的阵营、玩家、英雄、KDA、经济和伤害等数据。未取得的评分显示为“—”，不计入平均评分。战报不再附加客户端来源说明或重复的对局列表。

战绩列表先展示20局，滚动到底后每次追加10局。更换地图或日期筛选后重新从前20局展示，统计仍包含筛选范围内全部对局。网页只下载展示所需字段，不再下载完整客户端原始对局协议。

玩家资料卡按本次查询的角色显示头像、游戏昵称和段位称号，同一账号绑定多个角色时也保持对应。

单人战绩、周期战绩、历史查询和战局详情中的分享按钮支持娱乐模式，包括共鸣之战。详情和分享图片展示装备图标；共鸣之战另外展示四个槽位的技能名称与来源英雄，装备类共鸣保留效果名称。评分采用客户端确认的显示值。
