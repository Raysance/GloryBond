# HOK QQBot

王者荣耀与Steam群聊机器人，提供战绩查询、英雄统计、在线状态、游戏时长、AI聊天、定时提醒和消息事件规则。网页端提供战绩分享、AI运行记录及管理员控制台。

Bot和网页现在由同一个项目维护，网页页面和管理功能保持原有入口。

本私有仓库保留完整源码和实际配置；面向公开展示的脱敏版本及完整使用说明位于 [GloryBond](https://github.com/Raysance/GloryBond)。
