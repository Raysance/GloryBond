# GloryBond

QQ 群里的王者荣耀助手：查询战绩、分析表现、查看职业赛事，也能聊天、看图、画图、记住偏好和安排提醒。

[![GitHub](https://img.shields.io/badge/GitHub-GloryBond-blue?logo=github)](https://github.com/Raysance/GloryBond)

当前说明对应 **2026-10-14** 的功能版本。完整用法见 [功能手册](NBot/shared/agent/manual/handbook.md)，开发与运行前置条件见 [开发说明](docs/DEVELOPMENT.md)。

## 聊天、看图和引用

直接 **@机器人** 即可进入 AI 聊天，不需要 `#`。固定业务命令使用 `#` 或 `＃`；引用中的命令不会被执行，引用里的 @ 也不会单独触发聊天。

群聊回复开头会 @ 本次提问者。通常发送简洁的群聊版，明确需要完整依据或个人偏好要求详细时可发送详细版；运行记录中可查看实际保存的两个版本和过程。

可以发送图片、引用他人的图片后继续提问，也能理解具有可读取媒体地址的动态表情。动画通过若干抽样画面呈现，不能保证看到了整个动画；视频没有通用内容识别能力。图片损坏、无法取得像素或权限不允许时，会说明未读取。

指代不清时可以补查群聊背景。普通群只查当前群；管理员私聊可在授权范围内查询指定群，普通私聊没有群聊读取权限。近期窗口默认15分钟、20条，上限60分钟、50条，涵盖群内不同发言者，并明确摘录和截断情况。

正文或已验证引用中的网页链接会提取标题、正文、列表和表格供本轮参考。需要登录、反爬或动态加载的页面可能无法读取，不会把失败当成已读。

更多：[聊天](NBot/shared/agent/manual/chapters/chat.md) · [图片与引用](NBot/shared/agent/manual/chapters/vision.md) · [群聊背景](NBot/shared/agent/manual/chapters/history.md)

## 偏好、角色与提醒

### 记住与纠正

```text
@机器人 你需要记住我喜欢玩安琪拉
@机器人 不是辅助，我一直主玩中路
@机器人 现在不喜欢安琪拉了，主玩小乔
@机器人 忘记我之前那条英雄偏好
#清除记忆
```

稳定偏好和明确纠正可以保存或更新，不要求每次都使用“记住”。更新前会结合已有记录，同一事实的重复内容不会反复新增；未被纠正的其他偏好继续保留。只有实际保存成功后才确认。

临时状态、玩笑、疑问、引用他人的话或网页内容不会自动变成本人的长期事实。`nomem` 可关闭本次长期记忆使用。没有旧版的被动聊天记忆和凌晨自动提炼、清理原始群聊的行为。

### 角色和表达

可以查看已有角色、选择角色、要求联网补充新角色，并设置自己希望的回复长度和语气。角色影响表达，不能改变数据事实、工具权限或查询范围。

### 后续消息

```text
@机器人 10分钟后提醒我休息
@机器人 每隔10秒发一条“喝水”，发三次
@机器人 每小时查一次指定赛事的赛程，有结果就告诉我
@机器人 查看我的任务
@机器人 取消刚才的提醒
```

固定文字提醒和需要查询的任务都可安排。未指定首次延迟的周期任务会等待一个周期后开始；错过的时间点不会集中补发。后续消息发往创建时绑定的位置。

更多：[记忆边界](NBot/shared/agent/manual/chapters/memory_update_rules.md) · [角色](NBot/shared/agent/manual/chapters/roles.md) · [提醒](NBot/shared/agent/manual/chapters/tasks.md)

## 战绩、英雄与职业赛事

### 个人与群体战绩

支持今日、历史日期和区间战报，群体排行、在线状态及巅峰排名。条件查询可按玩家、日期、英雄、模式等条件找对局：0局说明未匹配，1局返回详情和图片，多局通常返回详情网页。

没有记录可能是尚未收录、战绩不可见或请求失败，不能直接解释为“从未玩过”。跨时间范围比较时，应同时看模式、场次和数据完整性。

<img src="assets/battle_detail.png" width="340" alt="战绩长图示意">

### 英雄信息

可以查询英雄表现、常用英雄、今日推荐、梯度和指定地区荣耀战力。英雄胜率和平均评分应同时看统计窗口与最少场次；官方累计战力、个人历史表现和 KPL 职业赛数据属于不同统计范围。

更多：[战绩](NBot/shared/agent/manual/chapters/games.md) · [历史查询](NBot/shared/agent/manual/chapters/history_query_rules.md) · [英雄样本规则](NBot/shared/agent/manual/chapters/heroes_sample_rules.md)

### KPL 数据

从 [KPL小助手](https://kplll.online/) 查询已收录的赛季、赛程、系列赛和单局 BP、战队、选手、英雄统计、分组及年度积分、MVP 次数、分均输出/经济/承伤榜和英雄组合表现，也能据此画图。

```text
@机器人 今天KPL有什么比赛？列出对阵和时间
@机器人 查今年KPL夏季赛安琪拉的选用次数和胜率
@机器人 比较某队中野英雄组合的场次与胜率
```

结果保留赛事、样本、来源及截断说明。第三方收录不保证官方实时或完整，抓取时间不等于数据更新时间；查询不会自动创建赛事订阅。

更多：[KPL 用法](NBot/shared/agent/manual/chapters/kpl.md)

## 分析、底蕴与代表局

### 底蕴如何理解

个人底蕴综合等价星级、MVP率、总战斗力、近期评分、当前英雄场次、英雄战力及近期胜率。当前评分因子使用固定基准8与近期平均评分；未授权、资料缺失或预设值会影响结果。

`#我的底蕴` 默认查看近7天已完成评估的正式对局，不把待评估样本按0补齐。**底蕴排行按双方团队底蕴均值的跨局平均值排序，不能当成个人单人底蕴排行。** 图卡以最高玩家为100%的显示，与统计中以有效玩家平均值为100%的口径不同。

具体公式和含义：[个人底蕴计算](NBot/shared/agent/manual/chapters/metrics_power_formula.md) · [统计与排行口径](NBot/shared/agent/manual/chapters/metrics_power_scope.md)

<img src="assets/real_power.png" width="340" alt="底蕴评估示意">

### 评分、贡献和时长

团队贡献系数结合个人评分占比与经济占比，按有效详情计算；它不是官方 MVP 规则。游戏时长默认查看两周：王者统计已收录对局的持续时间，Steam 使用已绑定账号的最近两周时长，不包含王者大厅或排队时间。

`#总览b-7`、`#总览e-7`、`#总览k-14`、`#总览i-7` 分别用于受益受害、评分极值、拿手英雄和组队交集；`#总览h` 是英雄受益受害统计。“受益受害”属于当前统计口径，不证明匹配机制针对某个人。

更多：[团队贡献](NBot/shared/agent/manual/chapters/metrics_contribution.md) · [时长范围](NBot/shared/agent/manual/chapters/metrics_game_time.md) · [指标用法](NBot/shared/agent/manual/chapters/metrics.md)

### 代表局与预言

代表局从指定日期的可用候选中按高光、糟糕、极端三类指数挑选，不由 AI 凭印象决定。普通查询返回摘要、战绩图和点评，不附管理员计算调试信息。当天没有符合条件的比赛会说明。

实时对局预言及戳一戳评估提供双方实力的参考，不能保证比赛胜负；观战截图也需当前对局支持并满足读取条件。

更多：[代表局筛选](NBot/shared/agent/manual/chapters/representative_rules.md) · [戳一戳](NBot/shared/agent/manual/chapters/poke.md)

## 图表、创作图片和表情

统计图使用实际查询数据，可以生成柱状、折线、热力图等图表。缺失、截断或小样本会说明，不通过虚构数据补齐曲线。

创作图片与看图是不同能力：当前文字聊天和图片理解使用 DeepSeek V4.1 Flash；创作图片使用 APIMart，初始模型配置为 `gpt-image-2`，实际运行设置可调整。通用 AI 生图工具当前以文字提示词生成图片，QQ `#emoji` 有单独的模板及参考图流程。

```text
@机器人 把我最近英雄胜率画成柱状图
@机器人 画一张王者主题海报
#emoji
#emoji 001 震惊但嘴硬
#emoji template=奶龙 prompt=委屈地说我没事
```

## 订阅、自动推送与记录

B站订阅支持 UP 搜索、最新视频查询、查看与取消订阅；按 UP 身份跟踪，改名不需要重新订阅。每位用户最多订阅1位 UP。后台通知接收范围由部署设置决定，不保证直接推送到所有群。

每日战报及代表局按配置向接入群推送，当前日常推送时间为23:30；固定 KPL 赛果推送与自然语言查询 KPL 是两项功能。

AI 运行记录可以查看实际输入、工具调用与结果、回复版本和 token 用量。未采集的字段不会伪造补齐；分享链接有有效期。记录可能包含对话和工具内容，分享前应确认内容适合公开。

更多：[订阅与推送](NBot/shared/agent/manual/chapters/subscriptions.md) · [运行记录](NBot/shared/agent/manual/chapters/logs.md)

## 常见问题

- **为什么没有回复？** 检查是否直接 @、命令前缀是否正确，以及群/用户是否获准使用；冷却、维修或休眠也可能影响回复。
- **为什么查不到全部历史？** 数据尚未收录、战绩不公开、缺少授权或查询条件不匹配，都可能导致缺失。
- **工具失败了怎么办？** 回复会根据实际错误说明限制，并在合理范围内修正或改用其他来源；不会把失败说成成功，也不会盲目重复发送可能已生效的操作。
- **能不能问机器人自身的功能规则？** 可以。功能手册包含用法、计算口径、样本、默认范围和限制；缺少依据时会进一步核对对应功能。
- **本地网页与 QQ 一样吗？** AI 聊天复用相同能力；QQ 专属命令、实时成员资料和戳一戳仍依赖 QQ 接入。
